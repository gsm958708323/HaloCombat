# 连招编辑器使用验收

在隔离 SkillLab 宿主中打开 Arena 工作区，选中「弹药射击 → 确认连段二段」。检查区显示 Fire1 对应的 ArenaPrimary 输入、命中确认条件和 0.5–0.8 秒窗口。鼠标与键盘均可选中连线。「添加下一段」以二段为前置，保留 ArenaPrimary，目标待选择。

- 选中场上 `target-1`。输入起手并单步后停在第 1 帧，第 14 帧获得命中确认。第 23 帧重试输入，第 24 帧显示等待窗口且缓冲有效，继续单步后在第 28 帧接到二段。
- 同样的布阵在第 29 帧输入，第 30 帧直接接到二段。帧记录能定位输入、实际命中与接续结果。
- 隔离网页将目标改为同阵营。窗口内输入时，检查区显示「接续窗口已开启，候选均缺少本次命中确认」，执行路径只包含起手。另用实际 Arena JSON 向空地输入验证相同的未命中判断。

前端作者测试 128/128，构建通过。浏览器控制台 Error 0。上述路径使用现有预览宿主和真实战斗核，修改集中在网页端。浏览器截图与测试日志保存在本地验收目录。
