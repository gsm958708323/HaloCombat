# 连招作者语义与运行反馈验收

开始：2026-11-16；完成：2026-11-17。对应 [ADR-0048](../adr/0048-combo-authoring-intent-and-runtime-explanation.md) 与[连招编辑器设计与使用](../连招编辑器设计与使用.md)。

## 交付内容

- 起手绑定、动作接续、公共取消、规则总览共用唯一运行表，删除旧的按输入分图与工程设置内第二份表编辑器。
- purpose 可选标记用途；旧非空前置规则明确显示未标用途，保留运行行为，不根据技能名或输入猜分组。
- 自动展开跨输入接续，功能视图保存根技能、规则引用和布局；公共取消按明确集合集中维护。默认折叠其他接入来源，视图外仍生效的接续可检查、编辑或加入当前视图。
- 拖线和新增先进入草稿；新增或修改匹配字段均检查全表重叠，作者明确优先顺序。正向Tag不视为互斥，平级歧义拒绝；共享视图修改显示影响范围。
- 编辑图稳定，实际执行高亮精确到规则与来源；同一规则的其他来源不会被一并标成执行。右侧固定当前技能总览，连线条件在下方定位，实际时间轴按需展开。
- 真实决策记录区分窗口等待、状态阻止、未匹配、规则选中、资源拒绝和成功；缺弹路由记录实际换弹。循环和重复施放逐次保留，输入到期后不把历史等待误报成仍在等待。
- 诊断默认在预览启用，正式角色按需开启；独立64条有界通道和序号，不挤占原战斗事件，不开启输入录制。回放结果排除纯显示诊断，保留原战斗事件序号及格式1录制语义。
- 正式内容24条运行规则补全用途：11条起手、8条接续、5条公共取消；预置“连续攻击与派生”“交替攻击接续”两个作者视图。未改技能数值、接续条件、目标、输入和优先级。

## 时间轴面板可见性修复（2026-11-17）

用户实际页面选中“确认连段二段→弹跳与延迟炸弹”后，动作与接续窗口被挤成细缝。原时间轴在可收缩的flex列里使用overflow:auto，最小高度退为0；复现时实际高度21px、内部内容235px，形成不可用的嵌套滚动。现让中央内容区统一负责滚动，直接子面板不收缩，时间轴移除内部高度上限和滚动。展开表单依内容增长，不压缩图下方的其他面板。

同时修复切换工程时预览与连招面板使用相同兄弟key的问题，分别按组件职责和工程ID生成key，避免React保留错误的旧面板。
