# Unity 统一按键与剑客课程验收

## 四个入口和发布槽

- 通过 `Combat → 打开场景` 启动 Arena 正式、Arena 木桩、剑客练习场与 SkillLab。木桩入口的一次性标记在初始化时清除，随后从正式入口运行时进入正式模式。
- Arena 两种模式在 Game View 收到主技能和额外技能的键盘输入，事件中的技能顺序与 `Fire1–Fire4`、`Roll`、`Fire5`、`Homing`、`Monkey` 的正式绑定一致。木桩场点击 HUD 不施放，点击场地触发弹药射击。两入口均验证 `Esc` 暂停和继续。用隔离正式工程实按 `F5` 纳入两组发布包，再用 `F6/F7` 触发实际施放。隔离目录同时放置了损坏的第 3 槽，Arena 仍能读入前两槽。
- 网页将四招分别发布到四槽并同步，Unity SkillLab 从这些文件成功载入 `f6,f7,slot3,slot4`。按 `Q/E/R` 和小键盘 `1–4` 依次选择对应槽，场地左键施放第一槽。暂停时 `.` 由第 0 步推进到第 1 步，`F5` 回到第一槽第 0 步。将隔离目录中的第 4 槽写为损坏 JSON 后，重载失败并保留同一个世界快照、修订和代次。
- Unity 测试覆盖两个按键同时或先后按下、仅松开一个、全部松开以及从 HUD 开始的鼠标按压。逐键松开的时序由输入状态机测试覆盖。真实窗口的实按覆盖了双键同按及各入口的主要施放路径。

## 剑客课程

- `SwordPractice.json` 是实际网页「完整工程」导出原件，SHA-256 为 `CFC4318C3707EE638CA5570D922D808F598F8E829B7273514E29A90380F3F038`。Unity 练习场直接读取该文件，运行独立 `PracticeStrike/Step/Ring/Burst` 绑定。
- 隔离预览在同一课程上核对普攻实际扣血 12 并叠一层、空挥不叠层、护盾吸收 12 且扣血为 0 时不叠层。守环在目标距施法点 1、2、4 米时，仅 2 米靶获得减速。折步推进 20 帧后在有效窗口内回到原点，推进 122 帧后因原冷却仍在而拒绝再次施放，回返点已消失。
- 网页用三次教学普攻叠满蓄锋，在第 52 帧由连招工作台输入 `PracticeBurst`，进入三叠斩。Unity SkillLab 加载网页原始回放，81 步的 1,653 个值一致。Unity 剑客场提交同样的逻辑动作得到六次实际命中、总扣血 90 和蓄锋由三归零。另在真实 Game View 分别按 `R` 和小键盘 `4`，两次均触发三叠斩并消耗三层。实按折步及备用键触发一次折步和同动作回返，守环可见内外圈。
- Unity 剑客场在隔离障碍夹具中由 X=0 冲到 X≈−3。模拟回返落点受阻后位置保持 X≈−3，回返标记还在。恢复落点可用后再次输入，位置回到 X=0，回返标记清除。该夹具由测试临时调大角色碰撞半径制造阻挡，课程文件保持网页导出原件。

- 回放、网页下载原件、独立发布快照与实际按键事件保存在本地验收目录 `Tools/SkillLab/.local/verification/sword-practice-20261122`。设计决策见 ADR-0051。
