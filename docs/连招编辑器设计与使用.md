# 连招编辑器设计与使用

## 查看全工程接续

打开「连招」，从总览根节点查看当前工程的接续。画布只投影 `runtime.combos` 中 `preSkills` 非空的规则。空前置规则供运行时起手匹配，可在工程运行配置中查看。

同一个技能可以在不同接续分支各有一张引用卡，连线从前置技能接到该分支附近的目标卡，并标出输入。每条规则的每个真实前置只画一次。遇到已在别处展开的技能，分支到引用卡为止。局部回环或自接续则指回已有卡片。根节点的虚线用于导览。

正式 Arena 中，连续输入 `ArenaPrimary` 可沿 `arena-ammo-shot → arena-combo-second → arena-combo-finisher` 接续。二段还可用 `ArenaAura` 触发 `ArenaSecond-confirm-bomb`，连到二段分支里的 `arena-bomb-shot` 卡片。这些规则要求 `1017`（本次动作命中确认），实际接续还需满足窗口和施放条件。

## 编辑 Timeline 和规则

1. 选技能卡片，右侧显示该技能的 Timeline 和关联规则。各分支上的引用卡共享原定义与规则 JSON。选连线可直接打开对应规则及目标技能的 Timeline。调整接续窗口时，选连线的前置技能。
2. 在 Timeline 中编辑时间区间。内联轴写回技能，共享轴写回被引用的定义，影响使用该定义的技能。自动时序通过施放参数调整，即时操作没有可编辑的动作轴。
3. 在右侧编辑完整规则 JSON，填写 `id`、`purpose`、`preSkills`、`input`、`requiredTags`、`priority` 和 `toSkill`。多前置表示任意一个来源可匹配，所需 Tag 必须全部满足。多条连线可能对应同一条规则，修改会作用于该规则涵盖的全部来源。
4. 应用规则时用现有编译器校验候选工程。同输入、前置重叠的候选须用不同优先级消歧。校验成功后更新工程草稿，可用现有撤销操作恢复。保存草稿会写入网页工作工程。

## 预览连招

启动全工程预览，从起手开始发送真实逻辑输入。可暂停并单步查看接续窗口前后的结果。接续成功时，画布根据 C# 记录的规则、来源技能和本次施放编号，高亮实际接到的那张卡。角色回到空闲时清除高亮。

点选其他卡片可以检查它的 Timeline 和 JSON，运行高亮继续跟随当前预览会话。单技能槽用于试放所发布的技能及其依赖。要验证完整连招调度，请使用全工程预览或导出完整运行内容。
