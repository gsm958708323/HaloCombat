# 连招编辑器设计与使用

> 架构决策与协议细节见 [ADR-0054](adr/0054-combo-workbench-conditions-and-windows.md)。

## 分层工作台与画布

打开顶部导航「连招」进入新一代连招工作台：

1. **一技能一主卡（自由可编辑 DAG）**：画布左侧为「空闲起手」入口节点，每个参与连招的技能仅对应一张动作卡片（含类型色条、时长、公共取消角标与底部迷你取消窗/实时进度条）。卡片支持自由拖拽排版（持久化至 `editor.comboPositions`）与顶部「一键排版 / 适应」整理；双击卡片可直达该技能的节点编辑器。
2. **直觉连线编排**：从「空闲起手」或任意技能卡右端口拖拽连线到目标技能即可建立起手或接续规则；悬停卡片点击右侧 `+` 可快速搜索并连接下一段；点击顶部「+ 技能库」可浏览或直接将工程中的其他技能拖入画布；选中连线按 `Delete / Backspace` 可删除（全操作接入 `Ctrl+Z / Ctrl+Y` 撤销重做）。
3. **自动连招链筛选与全表总览**：顶部自动按连通分支识别独立连招链（`全部` / `弹药射击链` / `单发起手` 等），一键聚焦零维护负担；随时可切换至「全表总览」按类型、按键或关键字检索全部规则。
4. **顶部公共取消栏**：将全技能/多技能可打断规则（如闪避/格挡取消）收纳至 `editor.comboCancelRuleIds`（纯编辑元数据，不写入运行时包）。悬停取消标签高亮所有适用卡片；点击进入勾选模式后，直接点击画布上的技能卡片即可切换该技能是否允许被取消；支持一键「透视取消线」。

## 统一条件模型、分支独立取消窗与时间轴坞

1. **统一 `conditions`**：运行时 `runtime.combos` 已移除旧 `purpose` 与 `requiredTags` 字段，所有条件统一为扁平 AND 数组 `conditions[]`（每项支持「满足 / 禁止」取反），覆盖：
   - **Tag 条件**：如 `1017`（本次命中确认；取反即未命中挥空）、`1002` 地面、`1003` 空中或自定义 Tag；
   - **Buff 层数条件**：按施法者持有某 Buff 的层数判断（`≥ / = / <`）；
   - **资源条件**：按施法者当前能量或弹药值判断（`≥ / ≤ / = / <`）。
2. **分支独立取消窗**：每条非起手规则支持四选一触发时机——「通用窗（默认 `CommonTags.Cancel`）」「命名轨（Timeline 上 `kind: "cancel"` 且带 `channel` 的轨道，如 `dodge` / `delay` / `special`）」「自定义时段（直接在动作 `[start, end]` 秒区间触发）」「任意时刻」。
3. **底部宽幅交互时间轴坞**：选中技能卡片显示该技能的完整时间轴；选中接续连线 `A → B` 时自动联动显示**前置技能 `A`** 的时间轴并高亮该边对应窗口。支持直接拖拽各取消窗、边级自定义时段、Hitbox/Move/IFrame 区间边缘与效果触发点（按 50Hz / `0.02s` 逻辑帧吸附），并与实时播放头同步。
4. **右侧实时检查器与冲突消歧**：所有字段均为即时生效结构化控件；当同一前置与按键存在多条规则时，自动展示「同按键求值顺序」排序栈并支持一键调序消歧；底部保留可折叠的原始 JSON 抽屉。

## 实时按键手柄试玩

左侧预览区将当前工程所有逻辑输入呈现为与画布连线同色的按键手柄栏，支持鼠标点击或按键盘数字键 `1–9` 实时搓招，同时保留「暂停 / 单步 / 输入并单步 / 重置」精确查帧与简洁状态反馈。
