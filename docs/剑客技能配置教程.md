# 在 SkillLab 搭建剑客技能

## 打开课程

完整工程位于 [SwordPractice.json](../Assets/StreamingAssets/CombatTraining/SwordPractice.json)。在 SkillLab 的独立工作目录中打开 Lab 工作区，点击「导入」并选择该文件，再点「替换工程」。导入前可以将当前课外草稿导出备份。进入 Unity 菜单 `Combat → 打开场景 → 剑客练习场` 后点 Play。WASD 走到木桩附近，鼠标指向目标。左键普攻，Q 折步，E 守环，R 三叠斩。小键盘 1–4 对应同一组动作。

可以从仓库根目录另开一个实验宿主，让练习的保存和发布落到独立目录。首次使用需先按 SkillLab README 构建网页。

```powershell
dotnet run --project Tools/SkillLab/SkillLab.Host.csproj -- --port 4297 --data-directory Tools/SkillLab/.local/sword-course/data --publish-directory Tools/SkillLab/.local/sword-course/slots
```

浏览器打开 `http://127.0.0.1:4297/` 后导入课程。想把自己修改后的课程送到剑客练习场时，从「导出 → 完整工程」下载，然后替换 `Assets/StreamingAssets/CombatTraining/SwordPractice.json`，在 Unity 按 `F5`。

## 逐招搭建

| 技能 | 从哪个模板开始 | 设置与连线 |
|---|---|---|
| 教学普攻 | 近战刺击 | 「效果传递」选刺击，距离 2.4m、最多 1 个目标。施放延迟 0.02s、动作时长与冷却 0.36s。新建 `蓄锋` Buff，增层并刷新、持续 6s、上限 3 层。新增「技能事件」，把「实际扣血命中」接到「施加 Buff」的执行口，持有者选「效果来源自身」、层数填 1。 |
| 折步 | 冲刺打击 | 「位移攻击」选冲刺，距离 3m、速度 16m/s、前摇 0。施放节点展开「弹药与重施放」，把再次施放返回起点设为 2.4s、冷却设为 3.2s。 |
| 守环 | 来源独立的减速光环 | 区域中心选「来源位置」，外半径 3m、内半径 1.5m、持续 2.4s、关闭脉冲。删掉模板的「离开 → 驱散」，将「进入」接到 1s、移动速度乘 0.5 的减速 Buff。施放再接一条「受击与状态 → 护盾」，持有者选自己、数量 25。 |
| 三叠斩 | 扇形斩 | 有限连发 3 次、间隔 0.2s、延迟 0.06s、动作时长 0.58s。扇形攻击时长 0.08s、基础伤害 18、攻击系数与暴击概率填 0。施放节点选 `蓄锋`，消耗层数填 3。 |

最后打开「连招 → 起手绑定」。四招分别绑定 `PracticeStrike`、`PracticeStep`、`PracticeRing` 和 `PracticeBurst`。在「动作接续」添加「教学普攻 → 三叠斩」，输入同样使用 `PracticeBurst`，普攻窗口填 `0.18–0.34s`。独立课程已将 Arena 的 Fire1–Fire4 接到这四个输入。飞行、回返、区域和阶段时序由战斗核计算。

## 验收与自己动手

1. 在网页「连招」选普攻输入和 `target-1`。点击「输入并单步」，随后单步到第 20、40 帧，各输入一次。观察蓄锋到三层。将预览靶子的护盾设得大于单次 12 伤害并重置，再打一次，蓄锋不会增加。把瞄准点移离靶子试一次打空。
2. 折步后用同一按键返回。先把回返时限改成 1 秒，靠单步对照标记的消失时间。回返只在原冷却与回返窗口重叠的有效时间内可用。受阻时标记保留，落点恢复后可重试。
3. 把靶子放在距施法点 1m、2m 和 4m 分别重置试放。只有 2m 的靶子获得 1 秒减速。施放者当次获得 25 点护盾。
4. 三叠斩需要 3 层。第三次普攻提交后步进到第 52 帧，选 `PracticeBurst`，点击「输入并单步」。窗内会接出三叠斩，继续推进观察三次 18 伤害与层数归零。再把接续窗口改窄，重复同一个按键时刻，对照等待或拒绝原因。
5. 在「预览设置 → 输入记录与复现」开启录制。导出记录后在 Unity 的 SkillLab 打开 `Combat → Skill Lab → Load Input Replay...`，核对同一份记录的末态。导出完整工程可保留分析图和编辑布局。
