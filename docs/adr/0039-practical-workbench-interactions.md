# ADR-0039：按项目适配的传递切换与运行信息

日期：2026-11-15。状态：本批已验收。关联：C05、F08、I01–I06、K01/K04/K06、A08/O01/O02。

用户明确允许“因地制宜，你觉得哪种方式好用哪种”。视频继续提供功能和操作参考；具体信息密度、共享定义入口、额外选项与JSON字段采用HaloCombat已定义且验证的契约，不把未知隐藏枚举或逐像素相同作为功能完成条件。装备、公式、独立地图、冒险的排除范围继续保持。

普通效果传递卡片提供目标、区域、投射物、近战、位移、射线、召唤七种选择。一次作者事务转换已有 `projectile/delivery` DTO，保持节点、位置、运行数字身份和施放参数；主效果口在hit/apply之间映射，执行顺序不变。可用字段从既有schema派生，只保留单位和含义适用的值；弹体碰撞半径不能冒充区域作用半径。未有数字身份时使用现有分配器，没有引入新运行类型或第二套配置。

已不适用的事件连线移除，其独占的、原先可达而转换后不可达的分支保留为禁用节点。仍被其他有效入口使用的节点保持启用，原有断线草稿不被顺带修改；一次撤销恢复完整图。关闭持续区域或吸收端口也使用同一整理规则。若切换会使split丢失命中上下文，保留原图并明确提示先拆开该分支，不猜测替代效果。共享弹体/区域根的类型固定，继续从调用侧选择或更换引用，避免改变多个使用者的契约。

召唤优先选择已有且攻击技能不是当前技能的蓝图；无可用蓝图时保留明确待选择状态，提示补齐。完整递归与依赖验证继续由C#编译器负责，前端的初始选择不代替校验。

事件面板独立为RuntimePanel；纯视图过滤覆盖关键/全部、伤害含暴击、施放生命周期、生成、弹体判定、生命周期、拒绝、节点执行和布置。数量表示筛选后/保留记录。沿用运行时500条容量；新逻辑步在上，同一步内按实际Sequence递增显示，避免倒置执行顺序。清空只保存当前会话的显示序号，不修改事件、统计、输入日志或战斗世界；重置会话清除显示序号。实例默认显示名称、类型、剩余时间与当前动作，完整身份、状态、属性和弹道置于可展开详情，定位/驱散/移除仍真实可用。

右摘要继续由有效图派生，区分目标、施放、传递和事件结算；补充实际伤害类型、连锁/无限穿透描述、Buff叠层/Tag/属性修正和召唤属性/攻击技能。缺根、缺共享轴、缺Buff/蓝图明确显示问题，不用默认描述冒充可运行。所有53份模板的摘要均检查无NaN/undefined，也不写回源文档。

五类弹窗共用Dialog，定义dialog语义、Tab/Shift+Tab循环、Escape关闭、忙碌时拒绝关闭，以及关闭后恢复入口焦点。新建技能、工程、导出和内容ID弹窗已做实际键盘验证；本批导入文件选择遇到内嵌浏览器自动化超时，导入弹窗的键盘/全文件流程继续归O02最终验收，没有用接口检查冒充这项UI验证。
