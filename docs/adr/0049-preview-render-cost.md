# ADR-0049 网页预览的移动插值和事件列表按需刷新

2026-11-18，补充 ADR-0044。

## 现象与决策

网页按批次接收战斗快照。原先 React 在收到快照时写入所有实体的 SVG 坐标，插值循环又在每个显示帧重写所有实体，包括位置未变的目标。普通射击开启自动施放并走位的 22 秒采样中，47,905 次位置写入有 32,019 次与原值相同。事件区增长至默认 80 行后，即便作者停在列表顶部，浏览器仍持续维护视口外的行。

由插值层持有实体位置，使用完整实体 ID 绑定 SVG 节点。收到新坐标才安排动画，目标位置相同的快照保留在途插值。移除实体时释放动画，暂停、逐帧、顿帧、死亡和大位移直接采用真实快照。React 按生命值、高度、阵营、Buff 等可见属性更新图形。

事件保留数量为 500。列表先挂载 12 行，接近底部时继续加载，也可用按钮加载。滚回顶部收回额外行。没有新事件的快照复用同一份历史，已有行按事件身份复用，伤害飘字只处理新增区间。主动深入浏览历史时，已展开行的显示成本仍随阅读深度增加。

测试方法与读数见[连续施放和移动帧间隔验收](../验证/2026-11-18-preview-frame-pacing.md)。
