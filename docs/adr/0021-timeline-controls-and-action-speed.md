# ADR-0021 时间轴控制标签与动作速度

日期：2026-11-15。状态：已实施。关联N02/N03/N08。验收见`docs/验证/2026-11-15-timeline-controls.md`。

依据本地fae7872的SkillTimelineAsset/SkillDirector/Motor：Timeline拥有ControlTags租约，开始播放后取得，任何结束/替换/卸载释放；外部同名Buff租约不得受影响。ScaleWithActionSpeed为true时每步读取角色ActionSpeed，以max(.1,属性值)缩放Timeline dt，不缩放角色钟、冷却、Buff、能量恢复、已发射弹体/AoE或木桶周期。

JSON显式Timeline增加controlTags与scaleWithActionSpeed，编译时仅允许1011..1016六个具名限制、拒绝重复/null/错误状态Tag；角色/预览/召唤蓝图增加默认1的actionSpeed，Buff修正支持同属性。默认值不强写旧工程/发布文件，已有formatVersion1语义与修订计算保持稳定；不是恢复旧SO或双写路径。

Motor在现有Activity策略之外叠加限制：1011阻止自主走动/跳跃，1012阻止持续转向和后续吸附，1013阻止新施放但不取消自己的当前Timeline，1014丢弃本步技能增量位移/冲刺扫掠，1015丢弃本步受击位移，1016暂停重力积分并保留空中竖直速度。阻止的增量不积压后补；显式Teleport仍是独立离散操作，不由1014代替落点/施放守卫。

开始动作的朝向吸附遵守已有外部旋转限制，并在取得新Timeline控制租约之前执行。缩放后的Clip积分使用其实际重叠区间，完整播放的总位移不随速度改变；命中、取消窗、Payload与自然结束按同一动作时间推进。自身独立顿帧暂停全部动作时钟，不能趁顿帧消耗ControlTags期限。

SkillAim显式标记是否提供Yaw，与HasPoint分开；Facing选择可提供方向而无落点。导演优先用已校验的显式Yaw吸附，没有显式方向的教学调用才用已有输入朝向。避免直接施放中的身体/移动沿旧方向而投射物沿鼠标方向，非有限方向在付费/取得租约前拒绝。

自然结束沿本项目既有World阶段在组件Tick中释放控制，随后本步Motor可恢复输入；因此完成步结束时普通移动可能已前进一个步长。该阶段顺序由实际跨宿主/场景记录证明，旧分支双相位Motor与全部历史技能的逐步对照仍归N02/N03，不能把元数据接通当作其时序完全相同。

网页显式时间轴可勾选六种控制和速度缩放，角色属性/Buff面板可编辑动作速度；预览/Unity快照显示真实动作时间、时长、有效倍率和自有控制，Unity具名内置视图按真实Timeline相位采样。原AnimatorState/原角色和动画资源仍按N03/N08独立迁移，不把程序化显示当原动画完成。

验收包括六种限制独立行为、初次吸附/持续旋转、叠加外部租约、全部结束/失败/重开清理、加速/减速/动态Buff/下限/顿帧、位移总量、Payload时点、冷却/Buff/弹体不被加速、坏配置与默认修订稳定、网页编辑/发布及MCP实际Unity场景。重要节点通过后本地提交。
