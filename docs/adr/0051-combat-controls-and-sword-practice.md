# ADR-0051 统一操作入口与剑客课程

Unity 的物理按键由 `CombatControls` 定义，场景消费逻辑动作。输入合并记录实际获准开始的键，全部松开后结束保持。HUD 点击仅屏蔽鼠标施放。Arena 正式和木桩共用场景，木桩菜单启动时通过一次性 Editor 会话标记选择训练模式。剑客课读取独立的网页导出工程。

技能槽保留原文件身份 `f6` 和 `f7`，另增 `slot3` 和 `slot4`。SkillLab 的四槽事务使用同一个目录锁，按槽位顺序决定排布。Arena 的 F6/F7 调试入口只读前两槽，正式输入表仍由工程定义。

`requiredBuff`、`buffStackCost`、`returnWindow` 存在施放规则中，`innerRadius` 存在持续区域定义中。预览和 Arena 都从同一战斗核获得层数、去向和半径。历史数值夹具仅省略此前不存在的零内半径，非零内半径由新机制测试覆盖。
