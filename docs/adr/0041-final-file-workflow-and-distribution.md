# ADR-0041：文件闭环与Windows分发

日期：2026-11-15。关联：A08、C08/C09、L01/L06/L10/L12、O01–O08。最终产物验证结果见最终验收记录，未验证项不能以脚本存在替代。

导入改为明确的导入JSON弹窗：选择文件或粘贴原始文本，先由既有C#入口解析/校验，再展示内容和替换/合并选项。错误保留文本且不修改有效工程，忙碌时禁止关闭；完整复用Dialog焦点/Escape契约。文件和粘贴不维护两套解析器。实际下载原件已通过两种入口回读、合并、撤销并再运行。

最终逐模板HTTP验证暴露持续引导的TimelineDuration正无穷直接进入快照，System.Text.Json拒绝发送，原单元测试未覆盖这一真实HTTP边界。域内无限时长继续保留，只在独立读模型中把无固定终点映为null；没有放宽JSON有限数值要求或把Infinity当字符串输出。新增持续引导快照/复现回归，宿主自检逐个覆盖53模板闭包、导入、施放/保持/释放、300步和严格HTTP数值序列化。传送操作需要既有追踪弹，单独验证拒绝与有弹后成功，不能把缺前置时拒绝当样例运行成功。

最终协议审计同时补齐DTO整数边界：Json.NET默认会在领域校验前舍入小数身份、接收数字字符串。WholeIntegerConverter只读拦截整数/可空整数，拒绝小数、字符串、溢出和非有限值，精确整数`.0`旧身份继续合法，默认序列化与已发布修订不变。parameters字段仍由已有NodeParameters校验，不给非法值建兼容层。新回归覆盖版本、runtimeId、团队、数量及边界数值。

HostPaths定位源码或分发包中的明确内容根，支持显式root/data-directory/publish-directory/port，用于独立工作和验收。优先可执行文件所在内容根，避免从另一个源码目录启动包时写错工程；参数和端口校验，仍只绑定127.0.0.1、只接收对应loopbackOrigin。原默认4192、用户工作目录与发布路径保持；包内默认目录与源工程相互独立。

Package.ps1使用现有前端构建和dotnet publish生成win-x64 self-contained宿主、Web/dist、示例/正式JSON、启动脚本、协议/ADR/验收说明和校验清单，压缩为ZIP。包不包含用户`.local`工程或F6/F7，不复制Unity美术资源；Unity源项目继续作为游戏与原资源交付。包可在不打开Unity、不安装Node/.NET的Windows x64运行网页预览；发布到源Unity项目必须显式传目录，正式内容文件导出后按源工程约定放置。

独立验收使用4193和临时数据/发布目录，源4192服务和用户工作文件保留。UI文件闭环、Unity下载原件/输入同文件验证、全量测试失败及修正、包启动/校验和完整要求覆盖都需记录；发布脚本本身不能作为可运行产物证明。

浏览器整页刷新和关闭不会触发React组件卸载；只依赖effect清理会遗留会话并耗尽16槽。pagehide清空本地会话身份、递增版本并以keepalive DELETE回收，BFCache pageshow返回时重建。它沿用既有HTTP会话协议，不新增后台租约或心跳。真实浏览器在其他15槽占用时连续刷新4次均成功；前端100项及构建通过。崩溃/强制结束进程无法保证浏览器发送请求，宿主重启可清除该进程的会话；本地会话容量仍有明确拒绝反馈，不宣称此清理能覆盖进程崩溃。

独立分发基线已通过434文件manifest校验、从非工程目录运行及ZIP解压后运行，均HTTP200、53模板、保存/加载与普通射击80伤害。最终包由包含本ADR和刷新修正的提交构建，以包内sourceRevision定位源码，包外.sha256定位归档；验收后的交付哈希不写回包内，避免自引用和重复打包。
