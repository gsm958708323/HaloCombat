# ADR-0035：作者数值控件精度与单位

日期：2026-11-15。状态：已实施。关联UI-001、C04、A01/A07、O01。

作者参数为单一语义源。HTML range按step自动取整会让导入的0.05与步长0.1不一致；输入范围也可能只是常用拖动范围，例如伤害常用上限500而正式JSON允许9999。控件不能在读取/显示时改写这些数值。

NumericParameter统一处理数值编辑：range使用step=any以保留当前位置，只在用户拖动时按声明步长计算新值；显示范围包含导入数值，不将其夹回常用范围。数字框允许合法小数、负数和科学计数法，不按方便拖动的上下限拒绝合法配置。协议最终范围由既有C#编译校验，未添加第二套运行规则。

整数参数在Field中显式标记，不能从step=1推断：例如发射数量和顿帧需要整数，伤害和生命即使常用步长为1也可以是小数。未完成、非有限或非法整数输入只保留为本地文本，不产生工程更新；失焦恢复最后有效值，Escape取消未应用文本。方向键按实际单位增减，修剪JavaScript加减产生的无意义尾数；原JSON不会因展示而重新量化。

暴击概率使用displayScale=100，界面数字框/滑条/摘要显示百分比，写入JSON仍为0..1概率。17%只写0.17，单位换算在边界函数内完成，Core、协议与快照无新增显示状态。摘要使用相同格式化函数，不能另存一份显示参数。

滑条每次pointer或方向键手势显式开始/结束编辑事务，避免同一焦点下的多次调整合并成一个撤销；数字键入沿用获得焦点后的单次事务。外部撤销/重做/导入值覆盖编辑显示，自己的有效输入保留正常键入文本。长字段可换行，避免挤出控件。

本批重新查看用户原截图与缓存视频00:48画面，在1920×922产品视口比较列宽：原左栏约522、摘要约282；旧实现左430、摘要260。布局改为clamp列宽，实际左524.15、摘要282、画布1091.25；1280×720保持左350、摘要220。高级输入/复现/场景属性收在一个预览设置入口，默认保留试验空间。该修正只证明区域/数值控件这一部分，节点密度、菜单/端口和所有示例尚需继续按完整清单验收。

验证包括64项前端检查、实际小数/负数/整数/大数值/百分比/撤销浏览器操作，以及下载原件到Unity同文件复现；详见`docs/验证/2026-11-15-numeric-controls.md`。UI-001关闭，默认节点参数过多的密度问题另记录UI-002，不能以列宽对齐宣称完整1:1。
