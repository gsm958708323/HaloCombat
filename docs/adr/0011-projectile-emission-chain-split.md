# ADR-0011：多重发射、连锁与命中分裂

日期：2026-11-14。状态：本批已实施并验收，见[验收记录](../验证/2026-11-14-projectile-behaviors.md)。对应功能清单G02/G04/G05/G06/G07。视频可见参数为作者契约参考，隐藏边界按HaloCombat明确实现。

## 领域与数据流

多重发射属于发射请求，配置count/spread与开关；一次Timeline触发只支付原施放费用，均匀生成同一弹体定义的多个独立实例。有限角度对称覆盖两端，数量1朝正前方，360度按等分一圈避免首尾重叠。不用连发次数冒充同时发射。

连锁属于每颗弹体的命中后行为。每段先执行真实OnHit效果；达到本段maxHits后，若还有额外连锁次数，在命中点按半径搜索未命中过的存活敌方，排除墙后目标，再按最近或World.Random选择。额外次数不计第一段；有限穿透预算每段重置，完整实体已命中集合贯穿所有段；无限穿透无可触发的段终点，不能同时配置连锁，校验明确拒绝。没有下一目标正常终止，不平空命中、不新建一次施法。剩余距离和寿命跨段累计，连续扫掠消耗本步剩余时间。

命中分裂为独立效果节点，只能从投射物hit上下文触发，可与伤害用next显式前后排列。子弹从实际命中点沿入射方向均匀分布，不重用施法者枪口偏移；复用父定义及效果图。最大代数0表示关闭，子代按父代+1判定；伤害Power乘子弹倍率。继承模式使用父弹命中点的剩余路径长，固定模式使用明确子弹射程；子弹独立寿命从0开始。继承祖先命中完整EntityId集合，兄弟分支各有独立集合，不再次击中刚生成它的对象。

## 执行边界与规模

投射物命中直接进入现有World.Deliver/EffectPipeline后再决定连锁；不先把所有碰撞排队而让已死亡目标继续参与后续搜索。命中效果和终结效果顺序仍先命中后原因后通用结束。命中中产生的新弹体意图在下一ProjectileService Tick才生成，避免递归即时推进。

专用ProjectileHitContext由碰撞边界创建，保存父定义、命中点/入射方向、剩余距离、快照攻击/Power、代数、祖先命中集合以及发射家族；不能把这些状态写回共享ProjectileDefinition或扩大成通用运行图解释器。效果顺序只按显式edge.order。

SkillDirector为每次成功Play分配世界唯一CastId，SkillOrigin在发射时捕获，沿父子弹和命中效果保留；再次施法不覆盖旧弹体归属。同一次多重发射及其后代共用256枚总发射预算，最大8代；单次发射最多64枚，分裂最多32枚，世界最多512枚存活投射物。超限发布实际拒绝事件；生成预算只限制派生，不改变已接受施放的资源消耗。

Owner失效/死亡拒绝待生成意图，现有级联清理仍按原归属工作。已生成家族只共享发射额度；每颗弹体自己的路径、年龄、连锁预算和命中集合独立，重置世界不串状态。逻辑Hitstop冻结推进。派生事件与累计统计从实际运行产生。

## 验收

校验全部字段/范围、非法端口上下文、JSON往返、发布闭包；同时多发/扇形方向、360无重复、按住引导散射、无限穿透与有限预算；最近/随机连锁、无下一目标、墙/失效目标、跨段路径/时间、完整身份去重；分裂前后顺序、入射点/方向、代数、倍率、继承/固定射程、家族/世界规模及Owner清理；不同施法/世界独立。完成网页实际编辑/发布、同文件宿主/Unity PlayMode对照及Core/前端/Unity回归后关闭本批。
