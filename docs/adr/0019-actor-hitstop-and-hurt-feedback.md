# ADR-0019 角色独立顿帧与受伤反馈

日期：2026-11-15。状态：已实施。关联ENG-003/N02/N03/N08。验收见`docs/验证/2026-11-15-actor-feedback.md`。

历史fae7872的ActorTime每步先锁存pending请求，同角色取max，从下一固定步起停止自己的组件、Buff和Motor；全局顿帧仍是独立世界功能。已有弹体/区域不因Owner停顿而冻结，只有其自身被请求时才停。Frame计数不倒退，逻辑时长/资源/输入有效期使用角色实际推进时间，死亡与回收不等恢复后才处理。

保持现有世界Frame与教学全局顿帧入口。快照stopped描述本次已执行固定步，hitstopFrames显示待执行的剩余预算（含尚未锁存pending）；最后一个停止步可同时stopped=true、remaining=0，下一步恢复。世界停止期间不扣除角色独立预算。

每个Actor拥有ActorTime。World在全部角色组件前统一BeginStep；组件Tick、Buff、Motor、命中盒、弹体/AoE服务查询同一个停止标志，避免阶段间多停/少停一帧。伤害请求来源/目标独立帧数；角色停止不是无敌，仍可被其他攻击结算。正常松开/取消保持施法仍可响应，但停止期间不能新启动技能。

JSON伤害节点增加sourceHitstopFrames/targetHitstopFrames与feedback等级；原hitstopFrames保留其明确的世界冻结语义，不作为独立顿帧兼容字段。等级为基础/轻/连段/重/终结表现信息，不按硬编码SkillId隐式改帧数；旧技能迁移时把原等级推导结果显式写入其伤害节点。动态连段确认等其余历史规则仍按N02迁移，不能使用全世界HitIndex猜每次施法中的第几次命中。

hurt-feedback是独立效果节点，接在伤害后，默认仅当当前上下文真实扣血且目标仍存活时发EvHurt；可显式关闭扣血条件以表达主动反馈。致命一击由死亡表现负责。事件保存完整Source/Target/Origin及等级，ViewRegistry按完整EntityId路由；退订和重开清状态，旧代事件不能作用新对象。

Unity只消费反馈事件和停止采样，模型脉动/动画相位在自身顿帧时停，反馈闪白/短位移使用wall time淡出，角色真实Transform不由表现改写。网页显示每实体停止/剩余帧/角色时间和事件等级；快照是只读模型，不把可变ActorTime共享到网页。原Animator/Cue资源迁移仍独立，当前程序化反馈不能声称像素还原。

反馈wall时间从事件实际发生时记录，不能拿整个当前渲染帧的delta去扣一个刚在帧末发生的反馈，否则长帧会让第一次显示之前闪白已归零。该时序由Unity PlayMode实际视图验证。

验收覆盖下一步锁存/max合并/恢复精确步数、来源与目标独立、不同实体/世代隔离、Buff/能量/输入/保持施法/位移计时、无关弹体/区域/木桶继续、停止实体仍受击/死亡/回收、反馈存活/护盾/无敌/致命边界、实际视图与旧事件隔离、网页编辑/发布/跨宿主快照及完整Unity测试。重要节点验收后本地提交。
