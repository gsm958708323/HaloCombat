# ADR-0029：工程与运行 JSON 导出

- 日期：2026-11-15
- 状态：已实施
- 关联：L04/L12/O02；最终交付JSON的完整文件闭环。

## 契约

工程导出使用既有SkillProjectDocument，保留编辑布局，允许空工程与断线草稿。当前技能运行包复用SkillPublicationDocument，裁剪真实依赖并保留根技能和修订，可直接放入SkillLab的槽文件。完整运行内容使用同一SkillProjectDocument，完整编译并要求正式角色定义后，通过独立JSON树省略editor和所有图节点position；保留全部技能、共享定义、Actor/Combo/Arena/Motor/Cue/View。运行内容不是第二套人工配置。示例工程无正式角色定义时明确拒绝完整运行导出，避免交付游戏无法加载的文件。

文件仍为JSON，Unity资源通过键引用、随Unity项目交付，不在JSON内编码Prefab。导出不会改变作者身份、当前会话或磁盘正式内容。下载文件名独立清理，不能把内容身份当作磁盘路径。

导入的原始文本先交C#读取，避免浏览器JSON.parse吞掉重复字段。工程与既有发布包分别按原契约验证；坏发布包不能当工程回退。导入结果独立返回needsLayout，不能仅凭零坐标猜测作者布局缺失：工程可有意将节点放在原点，必须原样保留。单技能包导入后选中原根，运行文件省略的布局在网页生成，只影响作者视图。替换、合并与撤销继续使用现有工程历史和引用映射。

## 验收

三种实际下载/文件回读、布局与运行语义分离、精确依赖/稳定身份/重复字段/修订损坏已验证。实际下载的9a2df1db单技能包在Unity SkillLab运行120步，1命中/120伤害；与宿主15/60/120步1285个值对照，最大数值差5e-8。4e14a75a完整包经ArenaBootstrap/RuntimeProjectLoader实际加载，120步3次施法/3次命中/189伤害，与原内容状态和事件一致。用户工程和两槽保持字节一致。详见JSON导出验收记录。
