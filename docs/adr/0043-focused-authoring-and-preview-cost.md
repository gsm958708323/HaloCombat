# ADR-0043：当前技能配置、节点属性与预览成本

日期：2026-11-15。关联：A/C/J/L。用户要求配置只看当前技能、右侧仅显示选中节点，排查预览卡顿；补充网页默认关闭输入记录、默认无限弹药。

## 编辑边界

配置页展示当前Skill图的JSON，省略位置和默认启用字段；应用原始文本时保留其他工程数据及同身份节点的位置。完整候选仍经既有C#校验，身份修改要求走原重命名入口，重复键不能被浏览器JSON.parse悄悄丢弃。它没有新增第二种运行协议或反向猜图转换。

卡片与选中节点侧栏共用NodeParameters。技能/定义级设置、时间轴、摘要和连线排序移到工具栏弹窗，工程/角色/连招/蓝图移到工程设置，未删能力。空选中显示提示，多选显示最后选中的节点。

## 已定位成本与修改

旧WorkBench持有usePreview，收到每次快照都使整个编辑器重绘；其中未保存判断和预览语义键每次序列化完整工程，右侧也重新派生全部摘要。预览状态移至独立PreviewSession子树，语义键按工程引用/当前技能/试验选项缓存。事件/实例诊断面板每200ms更新，实体画面独立更新。

旧输入记录对每条命令执行JSON写入、读取和再次校验，直接命令校验也先序列化再解析。相同机器1万条瞄准命令：旧记录开启约762ms/296MB分配，绕过记录仍214ms/76MB；改为类型化字段检查和独立DTO复制后，开启约41ms/3.1MB，关闭约11ms/1.5MB。该微基准说明输入处理成本，不代表游戏帧率。关闭记录时连初始工程快照也不创建；现有Unity录制调用保留显式既有行为。

播放原每60ms串行发送施放/瞄准/步进，每个请求都构造完整快照；现在按20ms调度，把同批有序命令一次提交、只返回一次快照。等待请求期间不丢弃经过的墙钟时间，逻辑步长仍0.02秒，原有追帧预算与版本隔离保留。批请求先完整解析校验，重复字段拒绝，命令不绕过原施放守卫。

## 试验选项

网页记录默认关闭，手动开启从新世界记录；开关切换重置，避免导出缺前半段的伪完整复现。关闭时导出/重放禁用，导入外部记录继续可用。

无限弹药使用AmmoComp明确免耗弹策略，正式工厂默认false，网页只为施法者创建该策略；不修改技能费用、容量、发布内容或召唤蓝图。UI显示∞，关闭后恢复有限消耗和缺弹守卫。可选preview.unlimitedAmmo默认false，仅在输入复现文件描述试验条件；网页恢复作者内容时移除临时值。
