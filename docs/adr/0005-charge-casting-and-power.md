# ADR-0005：蓄力施放与效果倍率

日期：2026-11-14。状态：实施中。视频仅展示蓄力菜单，没有给出完整字段；以下是 HaloCombat 的明确项目契约，不声明为原作者的隐藏实现。

## 施放契约

- 施放模式为瞬发、引导、蓄力。蓄力按下时经过同一状态/目标/能量/冷却守卫，接受后预付启动能量并开始冷却；保持期间不生成效果。
- `chargeMin` / `chargeMax` 单位为逻辑秒，0 ≤ Min < Max ≤ 120；松开早于 Min 则取消，不退款。有效释放时，倍率从 `powerMin` 到 `powerMax` 在 [Min, Max] 线性增长并封顶。
- `autoRelease` 为 true 时到 Max 自动释放；false 时在满进度等待松开。蓄力每秒消耗使用已有 `energyPerSecond`，仅保持阶段扣费；能量不足直接取消，不自动发射。
- 释放之后才推进 `delay`（释放前摇）和 `duration`（释放后的动作总长），本批蓄力一次释放一份效果包。连发、引导的旧字段在切换为蓄力后不参与执行。
- 在释放边界根据最新瞄准重新解析目标/点/方向并锁定，之后的延迟不追随新输入。失效 EntityId 按已有目标规则处理，不匹配同索引新实体。
- 受击、死亡、卸载、重载、失焦和指针取消清理蓄力；失焦取消与正常松开释放是不同输入。已释放的弹体不会因松开/失焦回收，仍由自身生命周期管理。

## 时间与数据边界

蓄力计时属于 TimelinePlayer 的播放实例，World Hitstop 时不推进；不在网页或独立状态机另计时间。原活动状态集合保持不变。倍率是每次播放/弹体实例的数据，不修改 SkillDefinition、Timeline、DamageEffect 或共享 ProjectileDefinition。

使用既有 `EffectContext.Power` 传播倍率，正式效果仍经 World.Deliver / EffectPipeline。伤害先将 `Atk * Coeff + Flat` 乘本次倍率，再应用防御和现有暴击/增伤/护盾规则；1 倍保持原行为。投射物生成 Intent、实例、命中 Intent 与终结效果均携带同一倍率；后续其他传递节点加入时也须保持这条语义，不读取已结束施法者的当前蓄力。

试验资源新增可选 `initialEnergy`：省略/null 表示满能量；显式值必须在 [0, energy]，`energy` 继续表示上限。初值、上限和每秒恢复分别可编辑，不借用弹药。

## 验收

覆盖提前取消、最小/中间/最大倍率、自动释放/满蓄力等待、释放延迟、方向锁定、重复按下/冷却/能量不足、打断/死亡/失焦、Hitstop、跨实例定义不变、投射物倍率继承和独立能量初值。完成网页操作、宿主与 Unity 同输入对照、Core regress 及 Unity EditMode/PlayMode 验证。
