# ADR-0050 SkillLab 工作区草稿、节点布局与 3D 试验场

日期：2026-11-21

Arena 与 Lab 分别保存到宿主数据目录下的 `arena/project.json` 和 `lab/project.json`。Arena 从正式内容初始化。Lab 从模板内容初始化，并使用默认预览场景。旧索引和引用文件按原路径原样复制到 `backups/legacy-project`，全部复制完成才公开备份目录。按正式工程和模板工程的已知 ID 决定迁入位置。自定义 ID 才按是否包含 Arena 定义决定。两个草稿就绪后记录旧调用者的默认工作区。草稿已有索引时保留现有内容。备份保留原始字节供恢复，默认工作区记录使宿主重启时继续使用各自的草稿。新安装默认使用 Lab。

磁盘 `editor.json` 使用 `nodePositions` 保存 `kind`、`graphId`、`nodeId`、`x` 和 `y`。`kind` 使用图所在的集合名。读取草稿时把坐标还原到完整文档，缺少坐标时由宿主提供 `X-Needs-Layout`。工作区、展开的草稿和缺失坐标的身份共同决定 ETag。运行加载跳过编辑文件，旧内嵌位置也会被忽略。公开可携带文档仍使用 `nodes[].position`，不接收 `editor.nodePositions`。`--migrate-tracked-layout` 仅迁移模板和正式索引，核对展开内容和坐标覆盖保持一致。

跨工作区复制从选中的技能开始，按战斗编译器实际解析到的引用加载依赖并提取所需 Cue 和 Body View。闭包内编译错误按原字段报告，休眠引用仍提供解除绑定预览。复制者在目标工作区重新分配 ID。正式发布请求携带已保存 Arena 草稿的 `If-Match` 并使用空请求体。宿主在草稿互斥锁内核对版本并将通过编译的磁盘版本写入正式工程。

Unity 试验世界从发布包的 `preview` 初始化，与网页共享 X/Z 米制坐标。槽位的试验设置有差异时采用 F6 文件中的配置。正交相机与网格只属于表现。技能范围读取实际查询和运行快照，施放前使用非采样的索敌诊断。Buff 周期在技能来源中传递给派生实体，结算快照附带周期标签。该标签用于网页和 Unity 的跳字与诊断，format-1 回放比较继续使用既有字段。
