# ADR-0008：障碍、射线与投射物终结

日期：2026-11-14。状态：实施中。射线菜单可见但原视频没有公开完整参数，以下未展示细节属于项目约定。

## 碰撞边界

- `CombatWorld` 接收只读矩形障碍快照，二维障碍为无限高、轴对齐的实心矩形，具有稳定字符串 ID。Unity Collider 不参与逻辑结算。
- `CollisionWorld` 对线段/圆形移动体与矩形做连续检测，圆角使用真实圆弧求交，不用扩张矩形的方角冒充圆形。先命中的障碍决定停止点；同时命中按定义顺序决定。移动留极小接触间隙，允许从接触面向外/切向移动。
- 角色 `collisionRadius` 是移动净空半径，默认 0.4m；攻击几何继续以目标中心和攻击宽度计算，不偷偷增加旧技能命中尺寸。初始角色和 Place 落点不得与障碍重叠。
- 普通移动、Timeline 位移和受击位移在 Locomotion 最终积分处约束；冲刺判定也先截到合法路径，不能以请求终点命中墙后目标。近战的目标中心需对来源可见。
- 闪现只检查落点净空和射程，允许越过沿途障碍。施放守卫在扣费/冷却前检查，延迟触发时重新检查，落点无效时不发生位移和命中。

## 射线

delivery mode=ray，length/width（全宽）、pierce/maxTargets 决定长度、扫掠宽度、首目标或穿透预算。障碍按半宽扫掠，墙与目标同距离时墙优先。目标按进入线段的距离排序、完整 EntityId 打破平局；不依赖注册表顺序。

apply 每个有效命中执行一次，wall 仅真正到达墙时执行一次，complete 始终在本次射线结束执行一次；后两者 Target 为空、Point 为实际结束点、Direction 为发射方向。若首目标/预算提前停止，则不再触发前方墙。全部效果继续经 World.Deliver/EffectPipeline，Power 原样传递。

## 投射物

飞行按连续线段检测目标和障碍，避免高弹速跨目标/薄墙漏判；命中排序同射线，每弹完整 EntityId 去重。range 为真实累计飞行距离（不计枪口前移），lifetime 为独立逻辑秒上限，先达到者终止；同一时点射程优先。枪口前移也检测障碍，不让弹体直接出生到墙后。

定义分别保留 OnHit、OnWall、OnRange、OnExpire（寿命）和 OnEnd（通用终结）。网页 hit/wall/range/lifetime/expire 端口分别映射，expire 是工具已有的通用结束端口。终结原因事件与对应效果只执行一次，再执行 OnEnd；命中效果 Intent 在终结队列处理前投递，防止 OnEnd 跑在命中伤害之前。Owner 清理仍是明确的回收，不冒充自然寿命结束。

## 作者与视图

PreviewDocument 可编辑障碍列表；空列表省略序列化，新增可选 collisionRadius 在默认值时省略，以保持规范化默认字段稳定。非有限/重复/非正尺寸、出生重叠均有具体字段错误。网页在预览侧栏添加/移动/缩放/删除障碍，变更完整校验后重建世界；不新增独立地图页。网页与 Unity 从核心快照绘制障碍、真实射线和碰撞结果。

## 验收

薄墙、高速、圆角、接触面脱离、移动/冲刺/闪现、射线首目标/穿透/预算/墙/终结上下文、投射物五类事件顺序/不重复、射程和寿命区分、蓄力倍率、非法布置、网页发布及 Unity 同文件对照；Core 全回归与 Unity 相关 EditMode/PlayMode 必须通过。
