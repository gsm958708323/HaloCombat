# ADR-0047 实际工程的连招视图与启动一致性

日期：2026-11-16。状态：采用。追踪：`docs/需求复查-2026-11-16.md`。

## 发现

三节点测试图不能代表正式表的使用体验。正式表24条规则包含11种输入和多个前驱，全部展开到三列网格后交叉密集，默认最小缩放还会裁切。工作/正式工程保留旧预览布置，截图中的新默认仅存在于隔离测试工程。BAT发现端口就跳过构建，不能证明当前代码已经生效。

## 决策

- 连招视图默认按输入筛选，保存的仍是原runtime.combos；“全部输入总览”提供完整查看。布局从起手按接续层级展开，循环/反向边保留，允许0.1缩放；提供适应与一次可撤销的自动排列。新增连接使用当前输入；移除引用只影响当前输入，其他规则和技能保留。列表、试放按钮和图使用同一筛选。
- 默认布阵仅修改预览的位置、目标数量和障碍，保留已有实体身份、属性、资源、种子与输入选项。打开正式内容时使用新试验布阵，不改正式游戏规则；用户当前工作预览经备份后迁移。网页有未保存草稿时，不能用磁盘工程替换它来制造交付截图。
- BAT在仓库互斥内比较源码和产物指纹；一致复用服务，过期先构建再核对同目录进程并更换服务。用户数据和槽位不参与版本指纹。显式SkipBuild继续尊重已有构建，Rebuild可强制构建。HTML入口no-store，启动打开带launch参数的新文档；不强行刷新已有草稿。
- 活动动作捕获原作者映射直到结束，避免编辑期间旧DiagnosticSite落到新节点；映射随动作结束释放。旋风的实际判定角度为360，快照也必须报告360，不能沿用隐藏的扇形角度。草稿校验期间松键/取消/移动停止仍可发送到旧有效世界。

## 验证边界

基于实际正式24规则检查筛选、前驱闭包、布局不重叠、规则不改写；工作23技能仅更新preview。集中执行Core regress、宿主、前端、Unity编译与测试。浏览器自动操作被安全检查暂停后的页面复验单独记录，不把生产构建或旧截图当作当前页面已经验收。
