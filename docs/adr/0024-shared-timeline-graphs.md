# ADR-0024：共享时间轴图与确认连段

- 日期：2026-11-15
- 状态：已采纳并验收
- 关联：N02、L07、原fae7872的SK2012/SK2013→TL3013。

## 模块与数据流

`project.timelines` 保存独立动作图（id、name、nodes、edges、timeline）；`skill.timelineRef` 引用其身份，与技能内联timeline互斥。动作图拥有持续区间、离散触发和它实际用到的效果/弹体/AoE定义，没有目标/施放/技能事件根。技能保留target/cast和自身事件、消耗、冷却、缺弹回退；两技能引用同一动作时共享一份TimelineDefinition，运行态由各自导演/TimelinePlayer持有。

Config先注册共享身份、编译动作定义，再将技能引用映射为同一TimelineId。引用依赖进入既有闭包与循环校验；发布按实际依赖包含共享轴和Buff/召唤依赖，双槽或正式发布对同一共享身份不同版本拒绝替换。每次重载构建独立内容快照，不修改已在运行的动作定义。

网页扩展现有图画布、复制/粘贴、撤销、引用检查和导入合并到timeline图种类；技能可把已有显式动作提取成共享轴，或选择一个共享轴。提取移动原动作节点而非复制；不能提取与技能事件根混用的图，避免不明确的节点所有权。绑定共享动作会替换本技能旧动作图，界面明确说明且可撤销。复制绑定技能保留共享引用，复制共享轴才创建新的动作和效果数字身份。

技能自身的事件根及其可达效果仍属于技能，绑定动作时保留。命中反馈是技能的可选默认配置（hitFeedback）；共享伤害节点未指定反馈时按完整Origin查询施法者SkillCastComp的该技能定义。hurt-feedback的damage选项读取实际DamageResult，允许同一动作服务不同受击等级而无技能ID分支。

## 当前内容与验收

以原SK2012/2013共享TL3013为实际需求，保留.65秒动作、.25..65取消窗、.22秒PD4012、两技能分别耗弹2/3及缺弹回退。PD4012速度10/半径.16/寿命3/命中4/同目标间隔.15/伤害系数1.35/来源2目标4帧停止；命中后的BU5101属性修正由现有通用Buff组件承载。接上2001→2012→2013的1017确认边与优先级，不恢复旧专用玩家执行器。

验证共享定义身份和独立播放、修改同步、缺失/互斥/数字冲突、闭包/循环、两槽冲突保留旧局、网页图编辑/提取/复制/合并/重命名/删除、原连段输入/弹药/确认/顿帧、Unity真实动画与重开。其余旧技能和原资源继续分批迁移。
