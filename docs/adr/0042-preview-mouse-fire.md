# ADR-0042：网页预览左键施放

日期：2026-11-15。关联：J03/J04。用户要求网页预览增加鼠标左键开火。

左键同时承担布置操作，因此仅在空地、配置已就绪且没有修饰键时开始施放；角色/目标上的左键继续选择或拖动，Shift左键空地、右键和中键继续平移。界面提示与使用说明同步，避免点击目标时同时移动和施放。

空地按下先更新瞄准，再复用既有cast；松开复用release，引导/蓄力语义与工具栏一致。指针捕获保证移出预览后仍能松开；失焦、指针取消或捕获丢失清理本次输入。播放和逐帧保持原契约，快捷操作不自动恢复暂停、不绕过C#施放守卫。

本次仅修改前端手势路由，未增加配置字段、依赖或运行时技能实现。已有前端检查及构建通过，真实浏览器检查空地施放、引导/蓄力松开、预览外松开、实体拖动和修饰键冲突。没有扩大到Unity或战斗核全量回归。
