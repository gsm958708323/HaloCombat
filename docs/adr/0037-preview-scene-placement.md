# ADR-0037：试验场直接布置与独立观察视图

日期：2026-11-15。状态：已实施。关联J04/J07、D05、J09/J13。

预览拥有两类不同状态：作者布置决定新会话初值；运行时Actor/弹体/资源属于当前世界。拖动既有角色或目标时应保留当前逻辑步和世界，不能把一次空间调整实现成重置全部战斗。新增/删除目标、障碍与初始属性变更继续通过作者配置校验并重建试验会话，因为它们改变场景结构；界面在应用期间禁用运行输入。

统一place命令增加可选的完整entityId期望值，并保留稳定actorId场景身份。快照独立输出sceneId和完整实体身份，不以显示名或渲染数组下标推断归属。场景实体回收后映射不指向复用索引；旧世代拖动拒绝。前端只允许拖动有sceneId且存活的场景角色，不拖动弹体、召唤和可破坏物冒充作者初值。

位置更新先校验有限数值、场景身份/世代、存活和障碍净空。LocomotionComp新增显式TryReposition用于设置姿态，保持Y、动作、控制/速度、资源和当前逻辑步；清除未积分的旧传送目的地，避免暂停布置下一步又跳回旧位置。普通玩法仍使用RequestTeleport，在原Motor阶段积分，未改其行为。布置失败不修改姿态、不写入输入记录；命令成功记录placement事件和同一步有序输入，独立于伤害/施放统计。

网页拖动过程中只显示位置预览，放开后等待已接收命令完成，冻结新输入并提交一次place；成功才更新作者初始位置和当前会话语义键，继续使用同一世界/实体。布局编辑不覆盖，若期间工程语义改变或会话换代则拒绝过期结果。修改作者初值可以撤销，撤销按通常配置变更重建；输入复现从冻结的原始配置重放位置命令，不能把后来的作者坐标误当记录起点。

拖动的初步障碍提示使用与C#相同的圆/矩形净空几何，C#仍是最终裁决。已有同代角色可在暂停、动作和顿帧期间调整试验姿态，不隐式推进调度步。超过场景/记录上限仍按既有协议拒绝或要求重置，不能导出不完整的输入。

目标和障碍新增使用确定的空位搜索与稳定身份，避免Math.random产生重叠初值；最多各128个。目标可以直接选中/移除或在属性面板调整位置、碰撞半径、初值和阵营。Team省略时角色默认为1、目标默认为2，显式0..30映入实际TeamComp和选敌规则；独立整数转换拒绝小数/字符串隐式转换，不在DTO读取时偷偷四舍五入。

观察范围属于网页只读视图：滚轮绕光标缩放，右键/中键拖动或Shift方向键平移，复位根据作者角色与障碍边界适应实际容器宽高比。视图操作不修改JSON、移动请求、调度步或输入记录；WASD/普通方向键仍是角色移动。瞄准十字、定位圈和拖动预览不参与鼠标命中，避免装饰元素挡住角色。一个视图格始终代表1米。

验证包括前端77/77、宿主/Core回归、相关Unity EditMode/PlayMode、实际拖动/碰墙/目标增删撤销/缩放复位/阵营操作，以及浏览器下载原件同Unity复现。J04本批验收，完整投射物菜单、视频最终视觉与所有示例/发布全流程仍继续。
