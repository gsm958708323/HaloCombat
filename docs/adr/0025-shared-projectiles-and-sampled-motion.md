# ADR-0025：共享弹体图与采样运动

- 日期：2026-11-15
- 状态：已采纳，2026-11-15完成本节点验收
- 关联：N02、L07；原fae7872的PD4001/4012复用、PD4003正弦回旋、PD4005落地点曲线。

## 边界和数据流

`project.projectiles`保存具名弹体定义图（id/name/root/nodes/edges），root必须是projectile节点。图拥有弹道和命中/终结效果，`projectile-ref`节点只保存引用和多重发射参数。共享图中的根不保存multi/count/spread，避免把发射次数误当弹体定义。Config先注册身份，再编译定义，效果引用通过既有依赖图闭包/循环校验；单个定义只注册一次。

网页沿用共享图画布与引用操作；可从普通弹体节点提取定义并把原节点替换为引用。提取移动整条效果分支，若分支还被外部节点或Timeline入口直接使用则拒绝，避免抢走其他作者的节点。复制使用者复用引用，复制定义分配新根/效果数字身份，合并/重命名/删除同步所有图。

## 原运动

新增正弦回旋速度曲线：出程`speed*(sin(age/returnAfter*pi)+.1)`；返程`speed*(sin(min((age-returnAfter)/returnAfter*pi,.5))+.1)`，步首采样供本步接触子段复用。不能擅自把原返程的.5弧度夹取改成pi/2。

新增按落地点时间表的弹跳：每段高度`4*height*(segmentDuration/firstDuration)^2*t*(1-t)`。时间表是严格递增秒数数组，逻辑在落地点切分子段、发布反弹事件，寿命和命中/撞墙仍由原ProjectileService负责。现有重力/恢复系数弹跳保留。

非移除障碍策略让弹体停在碰撞点但继续消耗逻辑寿命，不执行普通撞墙终结效果。共享图只显示定义，发射次数和散射由引用节点配置。

区域吸收使用本逻辑步实际位移推导的弹体速度，停止和卡墙时水平冲量为零。时间表落地使用未消费相位索引，避免浮点边界反复或遗漏落地事件；发射平面保存在运行实例，不能改写共享定义。

共享伤害可选择沿用技能反馈或显式关闭；可选feedbackHitstop取显式帧数与反馈最低帧数的较大值，连段反馈按当前弹体的接触序号推导，不借用全世界伤害序号。正式普通弹体因而能在单发和双发动作之间复用。

## 验收

验证定义唯一性、引用闭包、前向引用/循环/数字冲突、旧发布修订、两槽冲突保留、提取/复制/合并/删除/撤销、原采样曲线/落地时点/停止与寿命、同一弹体多技能归属和Unity真实发布。逐步迁入原复用射击/回旋/追踪/敌方弹道；原炸弹的共享AoE链与其他表现资源继续后续迁移，不用复制同一SpecId的数据假装共享。

本节点证据见`docs/验证/2026-11-15-shared-projectiles.md`。原翻滚、炸弹共享AoE链、成长和剩余表现资源不在本节点完成声明内。
