# ADR-0031：运行事件与作者节点来源

日期：2026-11-15。状态：已实施。关联K05/H09/J11。

编译结果建立独立只读来源表：效果实例与运行定义身份映射到GraphKind/GraphId/NodeId。Core仅增加可选IEffectObserver接口，效果管线按原顺序观察每一次实际执行，不改变效果数组、顺序和Context；Config每个世界拥有独立的观察栈，嵌套调用结束或异常恢复父来源，不使用静态可变状态。

节点重复引用仍实际执行两次，分别记录执行序号；后续效果保持自己的来源。伤害、延迟弹体命中、Buff周期、共享图使用实际效果映射；出生/终结/回收通过具体定义与完整EntityId定位。日志明确区分“节点执行”与伤害成功，不能把一次空目标执行当成功伤害。未知来源保留空值，不按显示名、坐标、时间或最近施法猜测。

网页事件行可定位作者节点及来源/目标/实体，实例可定位定义。来源包含图身份，局部节点ID相同也不串图；跨技能查看时保留当前预览根和世界，选择其他技能正常重建预览。实体使用完整世代身份，已回收仅显示已回收；新会话清空实体选择。配置变动期间禁用旧事件定位，缺失/变更节点明确反馈。

来源表不进入交付JSON、不改变发布修订或内容身份，不把图坐标/通用编辑模型塞进Core。SkillLab与Arena创建世界时装配同一观察器；其他独立Core示例可不启用诊断。验收包括同名局部节点、共享图、延迟Buff、重复效果、异常/世界隔离、JSON往返、真实网页定位及Unity同文件事件来源对照。

Melee/Dash Clip持有不透明DiagnosticSite并随实际范围事件回传，由Config来源表解释；该索引只在编译快照中有效，不作为内容身份、不进入交付JSON。其余作者节点始终使用稳定图/节点身份。旧数值迁移签名忽略这一诊断字段，真实来源行为由独立测试验证。

前端54/54、相关PlayMode26/26、全量EditMode初验613项除一项测试漏计暴击外通过，修正并追加嵌套检查后最终相关29项无失败。实际网页Buff/共享弹体/实体回收定位、同下载文件a9f1b291宿主与Unity20/40/80步2614值对照通过，最大数值差3e-8。详情见`docs/验证/2026-11-15-author-trace.md`。
