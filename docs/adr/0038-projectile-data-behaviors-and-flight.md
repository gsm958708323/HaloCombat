# ADR-0038：投射物行为数据节点与飞行触发

日期：2026-11-15。状态：本批运行能力已验收。关联：C03、G03、G04、I06、K02、O03/O04。

参考画面可确认独立穿透/连锁行为节点、弹体的绿色行为输入，以及“接触敌人＝按投射物行为”“同目标命中＝全程一次”“飞行触发＝不触发”三个默认菜单。视频没有展开所有隐藏枚举；下述新增枚举是 HaloCombat 的明确协议，不能作为原作者隐藏选项或原 JSON 格式的证据。G03 的最终菜单对照与 P06 证据边界继续保留。

`projectile-behavior` 是定义数据，以 `behavior → behavior` 输入普通或共享弹体根；不进入 EffectPipeline，也不拥有运行身份。`pierce` 维护有限命中数/无限穿透，`chain` 维护额外跳数、半径、最近/随机选敌，每段命中数为1。每个弹体只允许一个启用行为输入；禁用输入恢复默认每段1次。独立行为与弹体行内 `maxHits/chain/chainCount/chainRadius/chainMode` 不可同时拥有同一策略。

既有已交付 JSON 的行内字段仍属于公开契约，由同一个 ProjectileBehaviorCompiler 转成同一份 ProjectileDefinition，没有第二条执行路径。网页“提取行为节点”一次移动字段并建立数据边，可撤销；手动连接也移除行内策略。提取共享弹体/区域时带走闭包内弹体的行为节点；仍供闭包外使用的行为要求先复制，不暗中改变其他使用者。复制、合并、摘要、禁用和布局都按图/节点身份处理。

接触策略 `behavior/end/continue/ignore` 分别按行为预算、首次有效命中终结、结算后穿过、忽略敌方接触；后三者不能配置连锁。无敌穿过保持原有不消耗命中预算规则。`sameTargetMode` 的 `once/interval/per-leg` 分别使用全程完整实体去重、正间隔重击、出程/返程各一次；分裂继承的祖先始终不能再次命中，同索引的新世代仍是不同实体。未提供模式时，已有正 sameTargetDelay 继续表示间隔重击。

`flightTrigger` 的 `none/time/distance` 关闭触发或按逻辑年龄/累计路径触发 `flight` 效果口。出生不触发，首次为一个完整间隔；时间下限0.001秒，距离下限0.01米。运动在真实触发边界拆分，含加减速反求时间、返程、反射、停墙和顿帧。终结优先于同边界飞行触发；存活的返程/反射先改变方向再投递效果。浮点固定步的时间容差按当前速度转换成距离单位，避免整点距离迟一个逻辑步。

触发上下文为原 Owner、Target=null、实际弹体位置/方向、原攻击快照或实时攻击、Power 与 SkillOrigin，不制造命中上下文；飞行分支不能连接只在命中有效的 split。可以接区域查询、Cue、其他合法效果；没有效果分支时仍记录真实飞行事件。每弹每逻辑步至多64次，超额发 `projectile-flight-limit` 并跳过该步积压，继续运动且下一步恢复；命中/墙/寿命/射程及现有派生总量限制继续生效。回调移除、实体代际与池重置受保护。

协议/编译、Core 调度和网页视图分别持有自己的模型。诊断事件增加独立 Flight 快照，保留模式、序号、实际年龄与路径，以及作者节点、CastId、完整来源/弹体身份；不把浮点数据拼进要求精确比较的结果字符串。正式旧内容使用新增字段的中性默认值；旧迁移签名仅排除这些中性值，新模式由真实执行测试单独验证。

新增四个可交付模板：独立贯穿、独立连锁、时间脉冲、距离脉冲，总示例53个。运行证据、首轮失败及修正、实际下载原件哈希和网页/Unity对照见[投射物菜单验收](../验证/2026-11-15-projectile-policy.md)。
