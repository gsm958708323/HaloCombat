# ADR-0002：JSON 领域转换与共享 C# 预览

日期：2026-11-14。状态：依据用户“正式开发、逐步推进”指令采用的实施决策。

## 决策

延续 ADR-0001 的 JSON 唯一内容源目标。协议/转换放在现有 Combat.Config，使用项目已有 Newtonsoft.Json 依赖；删除 SO 后该模块不依赖 Unity API。节点加载时转换为类型明确的运行时定义，不逐帧解释图。

浏览器不复制战斗算法。独立本地 ASP.NET 宿主提供编辑工程保存、验证、预览命令/快照与 JSON 发布；只监听回环地址。它和 Unity 使用同一 Core/Config 代码。前端使用 React/TypeScript 与 React Flow，实现图形交互。

施放的目标、资源和冷却通过实体上的专职协调能力处理；Director 继续拥有 Timeline，瞬时效果统一 World.Deliver。查询结果避免静态/跨调用共享，并明确生命周期。

## 影响与迁移

增加网页工具和独立本地宿主，不拆当前 Unity 程序集。扩展正式技能定义/施法参数，保持纯 C# Core。

渐进实现时原 Demo 可暂时运行；这不是最终兼容承诺。Unity 内容迁移完成后删除 SO 作者类、资产、Bake 与代码回退，更新场景和测试。未迁移前不把目标写成已实现。

## 验收

JSON 往返与错误路径；相同配置/种子/输入的预览复现；资源/冷却/拒绝施法无副作用；同定义多实体不串状态；Core build/regress、Unity 编译与相关测试、真实网页操作。最终以完整功能清单为准。
