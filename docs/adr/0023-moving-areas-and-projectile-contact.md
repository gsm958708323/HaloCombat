# ADR-0023：移动范围、弹体吸收与重复接触

- 日期：2026-11-15
- 状态：已采纳并验收
- 关联：H08、N02、N08；历史依据 `fae7872` 的 AD4102 / PD4003 / AoeService。

## 领域与数据流

区域定义保存静止/向前、移动速度、碰障移除、同队弹体吸收、水平冲量系数、每次半径增量和吸收效果端口。区域运行态独立保存基础半径、累计吸收次数、当前碰撞半径与水平速度；绝不修改共享 AoeDefinition。SpawnAoeEffect 保存事件中心和前方偏移，沿明确方向生成。

World 保留既有顺序：弹体运动/命中与终结 → 区域运动 → 区域吸收 → 占用差集/脉冲/停留/寿命。吸收按当前逻辑步的端点与同队关系判断，沿用原实现，不声称连续扫掠拦截弹体。先移除弹体，再发布吸收事件/效果；清理追踪与原世代引用，不执行其普通终结效果，避免吸收炸弹产生意外爆炸。同一弹体只能被第一个有效区域消费。

区域的水平冲量与基础前移相加；半径按 `baseRadius * (1 + absorbedCount * radiusScale)` 增大，查询、障碍、网页和 Unity 使用同一运行半径。区域自己被停止时运动/吸收/生命周期一起停止；拥有者停止不冻结已有区域。碰障移除保留既有 Removed/Exit 语义，不当作自然到期。

弹体 `sameTargetDelay=0` 保留原一次命中策略，正数表示按该弹体自身 Age 冷却。接触时刻使用扫掠命中相位，不能提前使用步首或步末时间。永久已访问集合仍用于连锁无环和分裂祖先隔离；冷却不允许重新命中继承的祖先。独立停止冻结 Age，因此冻结重复命中冷却。`passInvulnerable` 显式开启时免疫接触只确认施法，不消费命中预算或写入接触冷却。

## 验收

补充网页参数、吸收端口、实时半径/速度/次数与事件；正式迁入 SK2003/TL3003/AD4102，Monkey 输入使用真实通用区域节点。验证原值、同/异队、两区域竞争、横向冲量、碰障、半径参与查询、出生步、清理/重开、独立停止、接触冷却、免疫、祖先隔离、真实网页发布与 Unity 同文件结果。

旧十三技能的共享 Timeline（2012/2013）、其余内容/原资源继续迁移，不通过复制专用技能类掩盖这些缺口。

证据：[移动区域与重复接触验收](../验证/2026-11-15-area-interactions.md)。当前配置模型使用 `areaMotion`、`absorbProjectiles`、`absorbForce`、`radiusPerProjectile`、`forwardOffset`；没有开启时保持既有静态区域与一次命中。Unity 的区域边界不再被呼吸缩放改变，显示与实际半径一致。
