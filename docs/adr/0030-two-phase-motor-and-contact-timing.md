# ADR-0030：双相位移动与最后一步命中

日期：2026-11-15。状态：已实施。关联N02/N03、J05/J08/J11、H09与O05。

## 原因与边界

历史fae7872在查询前积分自主/技能移动，查询及结算后再积分受击位移和重力，并在查询后收尾Timeline。当前JSON分支把两阶段合为帧尾，且在组件Tick里提前关闭到期Clip、释放控制；移动判定使用旧坐标，最后一步Hitbox可能在查询前消失。网页Melee/Dash还直接在组件Tick查询，不能只移动World的一段循环。

保持当前+X/yaw约定、JSON数据、Activity集合、角色独立顿帧和矩形碰撞。无需新配置开关或旧路径兼容层；直接替换内部单相位调用。

## 调度契约

World固定顺序为：统一锁存ActorTime → 全部组件Tick → 全部角色自主/技能/离散Teleport移动 → 测试服务钩子 → 弹体 → 网页近战/冲刺查询 → 原Hitbox查询 → 有序效果结算与弹体终结 → Timeline到期Clip关闭/自然完成 → AoE → Buff → 受击位移/重力 → 回收。

```mermaid
flowchart LR
    A[组件与Timeline推进] --> B[自主与技能位移]
    B --> C[真实路径命中查询]
    C --> D[效果结算]
    D --> E[Timeline收尾]
    E --> F[AoE与Buff]
    F --> G[受击位移与重力]
    G --> H[回收]
```

两个移动阶段均遵守同一角色停止标志、Activity策略、控制Tag和CollisionWorld。重力每逻辑步只积分一次，受击位移不能改变同一步其他已收集查询的目标位置。自然结束的控制租约覆盖最后一个有效移动/查询步，下一步才恢复自主移动；更新ADR-0021原先“完成步已可移动”的阶段约定。

近战/冲刺仅在组件Tick生成类型化的一步查询意图，保存完整来源EntityId和Clip生命；在全部角色移动后解析真实坐标。中断、死亡、回收会使未执行的意图失效。冲刺从Motor记录的离散Teleport之后的实际起点扫到实际终点，不把传送路径当冲刺伤害，也不查询未走到的请求距离。Motor是移动碰撞的唯一裁定点，保存本步实际接触；冲刺据此结束，传送前路径上的墙不截短传送后的位移。表现范围使用同一查询数据，关闭和实际撞墙事件各发一次。

Timeline仍按原作者时点及实际区间重叠积分，零dt不产生Melee/Dash查询。到期关闭延至本步接触结算之后，包含最后有效区间；显式中断立即关闭，不补发自然完成端口。动作内明确的持续瞄准不再要求存在Move Clip/steer，仍受BlockRotate和硬锁定Activity约束。

## 验收

覆盖最后一步移动/Hitbox、最后命中先于完成、不同出生顺序的移动目标、同一步多来源命中与延后击退、一次重力、双阶段碰墙、取消及世代复用、独立顿帧、动作中瞄准和离散传送后冲刺。实际JSON包通过SkillLab和Arena加载，网页与Unity同文件/输入对照；受影响回归通过后记录结果和提交。
