# ADR-0045：按功能存储JSON与共享战斗修复

日期：2026-11-15。用户要求拆分集中JSON、修复弹体穿过目标、射击允许移动，并定位预览长期退化。

## 本次设计

磁盘project.json改为内容索引：身份/名称和files引用。技能、共享弹体、区域、Buff、时间轴、召唤蓝图分别按稳定ID一文件；preview/editor独立，runtime按角色、连招、Motor、Cue、View、Arena分文件。SkillProjectFiles负责受约束路径解析、组合及保存，内存协议与领域编译器保持职责；HTTP与下载仍传完整文档，单技能发布/输入记录是明确的可携带文件契约，不人工双写业务配置。

例子、正式内容、用户工作工程均迁移到该布局，迁移前保留原件并按展开内容核对。保存以同目录跨进程互斥保护读写，模块逐个原子替换、索引最后提交，写失败回滚本次触及文件；ETag覆盖展开后的全部模块，外部改模块也会触发冲突。Unity和宿主使用同一读取入口，校验失败保留有效世界。源码按功能目录参与Git，分发复制索引引用闭包。

已确认弹体查询仅以子弹半径检查目标中心，忽略目标碰撞半径；修复共享LineTargeting的扫掠体积，保留墙遮挡、阵营、完整实体身份与去重。射击自主移动通过明确的施放字段进入领域定义，普通远程自动时序默认允许；近战/冲刺及显式时间轴仍保留明确限制，不把所有Attack状态一律解锁。

长期预览以固定场景比较早晚窗口的逻辑成本、保留对象/事件/命令规模及页面请求，不用重置世界掩盖累积。仅新增对应回归与必要长时采样，Unity通过MCP验证共享逻辑和实际文件入口。完成后的实测结果补到本记录。

## 实施结果

三个磁盘工程已迁移：示例61个模块/索引2423字节，正式47个模块/索引2147字节，用户27个模块/索引1657字节。迁移命令逐个检查SkillProjectJson.Write展开内容完全一致，原件在.local/verification/functional-content，未提交用户工程或槽位。节点布局和所有技能参数保留。ProjectFileStore的ETag覆盖模块内容，外部改一个模块即冲突；完整候选校验仍在保存/编译边界进行。分发脚本复制索引引用闭包，dirty检查包含正式模块目录。测试夹具与正常入口均改用同一个读取器。

碰撞新增目标半径，普通/1000m每秒高速弹擦边及真正不相交分别回归。命中点改成正确的表面接触点，原爆裂模板默认场景因此从240/3变160/2；这是目标2相对真实爆点超过4米，更新旧断言而非放宽伤害或半径。射线宽度没有改动。新增cast.allowMovement，远程默认开启、近战/冲刺默认关闭，显式轴依据是否包含判定区间设默认；移动控制Tag优先，界面显示实际默认，可显式关闭。

## 长时成本与边界

旧代码在高频扫掠中为每颗子弹多次创建全场列表/候选数组，Actor.TryGetComp在查询sealed组件失败后仍扫描所有组件。查询改为只读遍历、精确组件失败直接返回；RegistryActive的可变遍历快照契约不变。网页瞄准只更新十字准星和输入引用，不对每个pointermove重绘整个预览；网络取样约30Hz而显示插值继续requestAnimationFrame，逻辑固定步不变。宿主关闭逐HTTP请求信息日志，错误仍记录。

同机器、同持续引导场景720逻辑秒/36001发：各窗口100存活实体、500事件、0轨迹，未发现无界实体累积。旧每120秒约1.63–1.64GB分配、6.4–6.8秒计算，新每120秒133–134MB分配、5.66–6.01秒；后半程没有持续增加。该对照主要证明GC压力降低和固定场景成本有界，不宣称所有技能/浏览器恒定帧率。真实网页持续245秒后3个存活实体、20个场景SVG元素、80条事件行，仍可移动/施放，浏览器Error0。

## 验收

前端102项、构建、宿主自检通过，后者覆盖模块读写/外部更改ETag/并发写/坏结构保留；新增模块往返和路径错误检查。Unity MCP编译成功，相关EditMode106/106，SkillLab碰撞/发布/移动/散射/分裂PlayMode7/7，Arena加载/槽/重开6/6，Error0。没有重跑无关全量。真实网页修改伤害42→保存到skills/basic-shot.json→发布F6→偏移0.4米目标命中42，另一轮连续移动通过。原始证据在.local/verification/functional-content。
