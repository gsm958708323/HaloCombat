# ADR-0033：历史 Arena 输入与效果对照

日期：2026-11-15。状态：已实施；完整历史运行迁移仍有后续项。关联N01/N02/N08、H05、J09、O04。

以本地Git历史`fae7872`的实际Arena资产和调用代码为依据，新增测试专用`OriginalArenaContract.json`。数据来自原13技能、12时间轴、7弹体、4Buff、4个可达区域和12条输入规则，覆盖768个基础值。比较当前独立编译产物的身份、耗弹/回退、时序/控制/Clip、效果数组的类型/数值/顺序、生命周期和输入表；遇到未知效果显式失败，不静默省略。原局部Z前方向按当前坐标约定映为X，原局部X映为负Z；Buff原到期表现清理由新显式removed端口承载。该测试数据不进入运行路径，也不是恢复SO的转换层。

输入只保留Core一份容量3的FIFO缓冲，每次按下立即保存ActorTime，超限移出最旧输入，所有等待项按各自实际按下时刻过期。删除ArenaSession中在队首执行后才给后续输入重新计时的中间队列。保持主攻击继续由PlayerAimComp独立保存，只有新的按下参与接续，暂停/失焦清空。ActorTime停止期间队列年龄冻结。

玩家角色新增明确的`inputBufferSeconds`字段，JSON边界限制0.01–10秒，Arena按历史配置0.8秒；既有教学角色默认0.2秒。正式工程的SkillLab/网页Combo预览采用Arena玩家的同一窗口，未配置Arena的独立预览保持默认窗口。网页在角色面板编辑该数值，重载后建立新角色，不修改现有实例。

修复正式JSON中的已确认遗漏：补回普通/敌方/追踪/回旋弹命中、寿命或返回分支Cue；PD4012保留原伤害→爆炸Cue→易伤数组，删除迁移时多出的HurtFeedback。原HurtFeedback仅要求目标存活，故对应节点关闭“必须实际扣血”守卫；其他用户新建节点维持原有明确语义。原吸收球使用Heavy反馈和实际3帧目标停止，原传送弹/炸弹保留无敌接触穿过策略。删除三个旧中间取消表，实际Arena动作只映射原12条规则。

地面燃烧恢复独立BU5103：持续2秒、0.4秒周期、1层、0.05系数；回旋灼烧仍为BU5102的3秒、0.5秒周期、3层、0.06系数。两者可以共存，伤害按原Buff调度时的来源当前攻击计算，不因合并定义互相改时序或系数。

Cue增加通用`stacksAsTier/maxTier`：开始时选择`实例键_当前层`，停止时清理1到上限。不同施法叠出的Buff层仍在持有者完整实体上归属同一组，`stopWithCast=false`的循环按明确实体/实例键停止；动作循环保留CastId隔离，旧动作停止不能移除新动作实例。不引入任何具体BuffId的特判。

跨宿主实际复现暴露Mono与.NET10默认float字符串不同：0.59999996和0.6使相同伤害被判成文字差异。伤害快照已有类型化DamageResult，故删除Result中的重复浮点文本，只保留目标标签；网页从absorbed+hpLost和目标名称生成显示。数值仍以原0.0001容差逐项比较，实体/来源/顺序和文字身份保持精确，不通过放宽比较掩盖问题。

本对照不能证明全部历史运行完全相同：未被原技能引用的AD4101/AD4103尚未进入JSON目录；传送重施放当前仍用独立0.02秒JSON动作，原代码在输入处理时直接传送，时序/守卫需继续审计。这两项分别记录为ENG-004/005，N01/N02继续未勾选。原音频缺失、最终视觉和完整操作验收继续保留原范围。
