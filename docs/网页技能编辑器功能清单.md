# 网页技能编辑器功能清单

日期：2026-11-14。状态：完整需求与验收范围，开发中；已勾选项须结合 `实施进度.md` 的执行记录。方向依据 [ADR-0001](adr/0001-web-skill-editor-json.md)。

目标：复刻参考视频 BV1cC4J6fEac 的技能编辑页面、二维运行预览、配置查看、JSON 保存/导入/导出及游戏发布闭环；让 HaloCombat 正式加载 JSON，移除 SO 战斗配置路径。

## 范围与证据说明

- V：视频画面中可见且演示过的操作或行为。
- M：画面中的菜单/字段可见，但没有完整演示其内部行为；纳入功能清单，细节由后续协议补齐。
- P：为接入 HaloCombat、完整 JSON 交付及可靠编辑补充的要求；不是声称原工具已有。
- U：视频仅露出入口或口头提及，没有足够资料定义完整原工具规格。

1:1 验收分为界面、交互、技能行为、文件与发布四部分，采用视频时间点和用户截图逐项对照。原作者未提供源码、完整 JSON Schema 和所有菜单，不能声称与原工具文件完全互通，不能将猜测字段写成已经确认的原格式。

本清单列出技能编辑器交付范围。用户已于 2026-11-14 明确排除装备、计算公式、地图、冒险四个独立页面及其导航入口；二维预览中的目标/障碍布置仍属于技能试验功能。未展示枚举的证据缺口在末节列明。

## A. 网页整体界面与导航

- [ ] A01 [V] 深色桌面工作台布局、顶部应用栏、第二层导航、边框、字体层级、节点配色和控件密度对照参考图。
- [ ] A02 [V] 左栏上方为事件记录/运行实例，下方为运行预览；中央为节点画布；右栏为技能属性摘要。
- [ ] A03 [V] 顶部显示保存状态，提供保存、发布到 F6、发布到 F7、导出、导入操作。
- [ ] A04 [P] 只提供技能编辑相关导航；按用户要求移除装备、计算公式、地图、冒险四页及入口，其他可见布局继续对照视频。
- [ ] A05 [V] 中央工具栏显示技能库、新建、技能名称、技能 ID，以及施放/传递类型标识。
- [ ] A06 [V] 预览提供测试场景/配置切换；画布提供添加、适应、自动排列和缩放比例。
- [ ] A07 [P] 参考桌面尺寸下做视觉对照；较小窗口可调整布局并保持控件可用，不以移动端重排取代桌面还原。
- [ ] A08 [P] 关键列宽、分隔区域、滚动区域、焦点、弹窗遮罩和选中高亮可稳定使用；浏览器原生标签栏、任务栏、视频字幕不属于产品界面。

## B. 技能库与编辑工程

- [x] B01 [V] 按名称/ID 搜索技能，分类展开/折叠，展示名称、ID 与数量，点击切换技能。
- [x] B02 [V] 新建技能弹窗、输入名称、选择模板、自动分配稳定 ID，生成可用初始节点组合，并立即出现在技能库。
- [x] B03 [V] 修改技能名称和 ID，切换后恢复各技能自己的内容和画布状态。
- [x] B04 [P] 复制技能及其节点/引用，分配新身份；重命名 ID 时更新引用并检查冲突。
- [x] B05 [P] 删除技能，检查被引用与发布槽位，给出受影响项；恢复误操作。
- [x] B06 [V/P] 加载预置技能；补充完整新建、空工程和恢复示例流程，不把示例代码当正式配置回退。
- [x] B07 [P] 撤销/重做，覆盖节点/连线/参数/技能操作；切换技能和保存不丢编辑。
- [x] B08 [V/P] 未保存/保存中/已保存/失败状态、主动保存、最近工程恢复与刷新恢复；明确手动保存，ETag条件写入防止其他窗口覆盖，保存中的新编辑仍未保存。
- [x] B09 [P] 工程文件保存所有技能、共享定义和编辑布局；正式运行文件从同一语义源导出，不单独人工维护第二份业务数据。

## D. 目标选择节点

- [ ] D01 [V] 指定位置/方向：朝预览光标或输入指定的逻辑点施放。
- [ ] D02 [V] 随机目标：配置索敌距离，在合法目标内选择，目标位置变化后重新按规则取目标。
- [ ] D03 [V] 随机方向：按明确随机源生成发射/移动方向。
- [ ] D04 [M] 目标菜单还包含指定目标、最近目标、施法者自身；与指定位置、随机目标、随机方向合计六种可见模式。
- [ ] D05 [P] 校验阵营、距离、死亡/失效目标、空集合和无有效瞄准的行为；选敌结果通过完整 EntityId 在实际触发时解析。
- [ ] D06 [P] 明确施放时锁定或每次触发重选、随机的抽取时机，以及节点输出的是目标、位置还是方向。
- [ ] D07 [P] 施法者、当前事件目标、选中实体与指定点等上下文用独立语义表达；目标实体失效后不把同索引的新实体当作原目标。

## E. 施放规则节点

- [x] E01 [V] 瞬发：能量消耗、冷却秒数、延迟生效秒数。
- [ ] E02 [V] 有限连发：开关、连发次数、连发间隔；每一发按真实时序生成。
- [x] E03 [M] 有限连发的逐段耗能开关；明确首段/后续段扣费、失败、中断和冷却开始时机。
- [x] E04 [V] 引导：启动耗蓝、持续耗蓝/秒、冷却、持续引导开关、有限引导时长、引导生效间隔。
- [x] E05 [V] 按下开始、保持持续、松开停止；可边走边引导，能量不足或被打断时按明确规则结束。
- [x] E06 [M] 蓄力：菜单中可见，完整实现开始、保持、释放、提前松开与中断；具体倍率、上限与耗费按 ADR-0005 的明确项目契约实现，不声明为原作者隐藏字段。
- [x] E07 [P] 能量作为真实运行属性，配置上限、初值、恢复与不足处理；与现有弹药区分，不把能量标签贴在弹药扣费上。
- [ ] E08 [P] 连发、引导、蓄力、冷却沿角色逻辑时间推进，处理 Hitstop、状态禁止、死亡、卸载和重复输入。
- [x] E09 [P] 秒级间隔跨过多个触发点时按真实次数补发；小于固定步长的间隔有明确规则，不随浏览器帧率变化。
- [ ] E10 [P] 打断清理待执行发射/延迟、输入与移动请求；有限连发或引导不是无界递归 Effect。
