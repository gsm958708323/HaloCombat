# 角色与动画 JSON 配置

正式工程入口为 `Assets/StreamingAssets/Combat/project.json`，`runtime.views` 为可选资源目录。目录保存资源键和状态映射，JSON 不保存 Unity 对象。`runtime.actors[].view` 可引用目录 ID 或现有内置模型。

| 字段 | 含义 / 约束 |
| --- | --- |
| `runtime.views[].id` | 唯一目录 ID，不占用六个内置模型名 |
| `resource` | Resources 内相对路径，不含扩展名，例如 `Combat/Actors/FemaleGunner` |
| `scale` | 在 Prefab 原缩放之上乘倍率，0.001..100 |
| `yawOffset` | 模型局部 Y 轴修正，-360..360 度，不更改 Core 的 0=+X 约定 |
| `states` | 大小写敏感语义键 → Animator 第0层完整状态路径 |
| `skills[].timeline.animation` | 可选动作语义，如 `Fire`、`Reload`、`Roll`；省略时不猜测动画 |

目录必须提供 `Stand`、`MoveForward`、`MoveBack`、`MoveLeft`、`MoveRight`、`JumpAir`、`Hurt0`、`Hurt1`、`Dead`。此外每个目录须覆盖工程显式时间轴使用的动作键，`Roll` 对应四个 `RollForward/Back/Left/Right` 方向键。现有角色使用 `Base Layer.Fire` 等完整路径。当前绑定支持单 AnimationClip 状态，加载时验证实际资源、Animator、Avatar、状态和 Clip。

| 表现状态 | 相位来源 |
| --- | --- |
| 技能动作 | Timeline 动作时间 / 总长；开启动作速度缩放时同步加速 |
| 待机 / 移动 / 空中 | ActorTime / 源 Clip 长度；循环播放，重复渲染不推进 |
| 受伤 | EvHurt 等级 + ActorTime；Heavy 以上映射 `Hurt1` |
| 死亡 | wall-time 清尸窗口；全局暂停时冻结，播放后保持末帧 |

相同技能连续施放通过完整 CastId 区分。角色独立顿帧冻结动作与身体动画；root motion 和 AnimationEvent 均关闭，Animator 不回写逻辑位置或命中。原 Controller 的自动过渡已移除。闪白使用 MaterialPropertyBlock，共享材质保持原值，角色回收不销毁资源。

网页先“打开正式内容”，在“角色与动画资源”选择角色视图、修改资源/缩放/朝向/状态映射，在显式时间轴编辑动画语义。新增目录或语义键可在“正式运行内容”的 JSON 中编辑并完整校验后应用。保存工程后“发布正式内容”，如使用 F6/F7，需从同一版本重新发布两槽。Unity Arena 按 F5 构建候选会话，全部验证和启动通过后才替换当前局；缺失资源、状态或版本冲突会显示错误并保留旧局。

网页运行预览继续显示真实 Core 的二维逻辑示意；本节点真实骨骼动画在 Unity Arena 验证。完整资源包、其余旧技能和全部原特效/音频另按 N02/N08 迁移。
