# Skill Lab

独立网页技能编辑器，JSON 校验/转换和预览使用实际 Combat.Core。已接通目标选择、瞬发/有限连发/引导/蓄力、分段耗能、投射物、目标/区域传递、范围伤害、持续区生命周期、近战/冲刺/闪现、射线与矩形障碍、召唤蓝图与分身 AI、共享 Buff 生命周期图、驱散/治疗、多重散射/穿透/连锁/分裂、Cue 和 Unity 试验槽；完整范围见仓库 docs/网页技能编辑器功能清单.md，仍在逐批实现。

在仓库根目录运行（需要 Node.js 22 与 .NET SDK 10）：

```powershell
./Tools/SkillLab/Start.ps1
```

浏览器打开 `http://127.0.0.1:4192/`。已有构建时可传 `-SkipBuild`。

数值框支持小数、负数和科学计数法；整数参数会明确拒绝小数，未完成输入失焦恢复最后有效值。滑条保留导入的精确数值，常用拖动范围不会截断合法大数值；方向键按字段步长调整。暴击概率显示百分比，JSON仍保存0..1。节点长标签换行，高级输入/记录/布置统一在“预览设置”中展开。

节点默认只展示主参数；“更多参数”“投射物行为”“更多事件”保留完整编辑入口。已连接事件端口始终显示，折叠不重建运行会话。右侧摘要沿实际启用连接、共享定义和时间轴派生，禁用/断开的草稿不冒充有效效果。

瞬发可开启“有限连发”，关闭只发一次但保留次数/间隔/逐段支付，重新开启恢复；引导与蓄力使用各自时序。随机目标/随机方向在每次实际且成功支付的触发时重新抽取，打断/未支付/无目标不多抽随机数。新建模板提供“死亡射击 · 二十发”，可直接修改间隔或切为引导继续试验。

试验场可直接拖动施法者和存活目标，Shift拖动吸附1米网格；松开后经真实位置命令更新，保留预览时间/弹体，障碍重叠则保留原位置。目标/障碍按钮寻找空位，选中目标后可移除并撤销；初始坐标、半径、阵营和属性在预览设置中编辑，结构或初值变更会重新应用场景。滚轮绕光标缩放，右键/中键或Shift方向键平移，“复位视图”适应作者布置且不重置战斗。点击空地指定瞄准，普通方向键/WASD仍控制移动。

运行预览展开“输入记录与复现”，可设置32位整数种子、重放本次、导出记录或从文件导入复现。文件保存当时JSON、种子、逐步有序输入和预期末态；不依赖现在工程的内容。复现停在末步，显示比较值数/最大差，成功后可继续编辑；导入会替换页面工程，可撤销，只有明确保存才写磁盘。坏记录保留当前预览并显示差异路径。

施放节点的“执行方式”可选择即时操作，用于传送追踪弹等没有动作时长的效果。它经过同一资源/冷却/状态/目标守卫后直接执行，不创建动画或时间轴，日志独立显示即时操作；Melee/Dash、引导/蓄力和技能生命周期必须使用时间轴动作。切换后可撤销，引用与消耗保留。

正式共享区域目录保留原吸收盾和黑洞。引用区域即可在网页/游戏运行：永久吸收盾按吸收数量扩大真实半径，黑洞通过“牵引方式→按时间衰减”按逻辑步使用原距离曲线；前方偏移和生成中心仍在引用节点配置。

Unity运行SkillLab后，通过`Combat/Skill Lab/Load Input Replay...`选择同一文件；成功后末态冻结，F5返回发布内容并恢复原推进模式。`Save Input Replay...`导出Unity本次输入。网页和Unity均走既有施放守卫，不绕过冷却/能量/状态。记录最多600秒或10000次输入，达到任一上限后请重置；超限不会导出残缺记录。网页失焦会暂停并取消保持/移动，倍速仍使用0.02秒固定步。

## 工程与节点编辑

“工程”菜单可改工程名称、新建空工程、恢复全部预置示例，或重新载入最近磁盘版本；替换和新建都可以撤销。空工程及暂时断开的节点图可以作为草稿保存。预览、配置应用和发布继续要求完整的 C# 战斗编译通过，草稿不会自动变成运行配置。

技能库按名称/ID搜索，显示分类与数量。技能、Buff 和召唤蓝图都可复制、删除或点击 ID 改名；改名保留数字 runtimeId 并更新类型化引用，复制重新分配身份。删除对话框列出工程引用和实际 F6/F7 发布包的影响；存在引用时选择替代项或返回修改引用。已经发布的独立快照继续保留原版本，更新需要明确重新发布。

画布支持 Shift 框选、Ctrl A 全选、Ctrl C / V 复制粘贴、Ctrl D 复制选中子图、Delete/Backspace 删除、Ctrl Z / Shift Ctrl Z 或 Ctrl Y 撤销重做。输入框内保留正常文本编辑快捷键，Ctrl S 保存工程。粘贴只包含所选节点和内部连线，会分配新身份，跳过目标图已有或不适用的根节点。“连线与执行顺序”面板可删除连线、调整同一输出的顺序；节点布局不改变执行顺序。拖动一次、字段获得一次焦点内的连续编辑各为一条撤销事务。每个技能/Buff 的视口随工程恢复，画布平移/缩放不会清空内容撤销记录，也不重建战斗预览。

采用显式手动保存，显示未保存/保存中/已保存/失败；刷新恢复最近磁盘版本，离开有改动的页面会触发浏览器提示。保存请求只确认发出时的快照，之后产生的新编辑继续显示未保存。宿主使用 ETag 条件写入和原子替换，其他窗口先修改文件时返回冲突，不覆盖较新内容；可先导出当前编辑，再重新载入磁盘工程后继续。

“导出”可下载三种 JSON，文件名会清理为安全的单个文件名，导出不修改当前编辑或磁盘正式配置：

| 类型 | 内容和加载方式 |
| --- | --- |
| 完整工程 | 保留全部作者内容、布局、选择和预览布置；允许空工程、断线草稿，回读后继续编辑 |
| 当前技能运行包 | 根技能、真实依赖闭包与修订；将下载文件复制为 `Assets/StreamingAssets/Combat/f6.json` 或 `f7.json`，打开 SkillLab 后 F5/Reload 载入，再按对应槽键施放 |
| 完整运行内容 | 全部技能、共享定义、角色/连招/Arena/Motor/Cue/View，省略编辑状态和节点位置；从“打开正式内容”开始编辑，完整校验且具有角色定义后才能导出。替换正式 `Assets/StreamingAssets/Combat/project.json` 后在 Arena 重开加载 |

运行文件继续引用 Unity 资源键，Prefab、贴图、动画、音频随 Unity 项目交付。单技能的两槽必须来自相同工程和共享配置版本；需要同时更新时使用“同步两槽”。示例作者工程没有正式角色定义，使用单技能包在 SkillLab 验证，不能作为完整 Arena 内容。

三种文件均可通过“导入”选择回读。原始文本先交 C#，校验结构、身份和共享引用，运行包额外校验修订与完整语义，再选择替换或合并；坏输入不替换当前编辑。替换保留工程文件中的场景和布局，运行包缺少的布局自动生成，单技能包选择原根；合并保留当前场景，为冲突身份分配新值并同步内部引用。两种操作均可撤销。`editor` 保存选择及视口，发布包省略它并规范化节点位置，因此移动节点或视口不改变发布修订号；模板出口仍保留作者布局。

“打开正式内容”读取`Assets/StreamingAssets/Combat/project.json`。这份工程含原SO内容迁移的G1/G2/闪避/追踪/光环/召唤技能、共享Buff、显式时间轴和runtime段。时间轴的取消/移动/命中盒/无敌区间、离散触发点和有序效果入口可编辑；显式时间轴独立管理时序，施放卡只调消耗/冷却，不能再套用自动延迟/连发。效果入口引用图内节点ID，可以重复引用；复制技能和导入合并会同步重映射，删除节点移除对应时间轴入口并可撤销。

显式时间轴可勾选六种动作限制和“随动作速度缩放”。限制分别作用走动/跳跃、转向、新施放、技能增量位移、受击位移和重力；通过独立Tag租约维持，停止/结束释放自己的限制，不清除外部Buff。开启缩放后按角色最终动作速度推进Clip/Payload，最低有效倍率0.1；角色/召唤蓝图/Buff均可编辑动作速度。冷却、Buff时长、能量恢复、角色钟和已生成弹体继续按自身时间。实例显示动作时间/倍率/控制；原Animator状态和资源仍继续迁移。

“正式运行内容”显示角色、Combo、Motor和Cue的JSON配置，可完整校验后应用；技能改名/删除也检查这里的AI/闪避/技能槽/连招前驱与目标引用。召唤属性仍使用共享召唤蓝图，正式Actor不另写一份。合并不同Motor或冲突Cue数字身份会明确拒绝，避免静默改写行为。

“发布正式内容”验证全部定义后写入同一正式文件。V1–V4的F1、训练场重置时读取，坏文件不替换已有世界；没有SO/代码回退。网页F6/F7发布仍裁剪技能依赖闭包，并携带Motor/Cue，拒绝两槽混用不同版本。Unity的Cue使用明确cube或prefab类型；prefab/音效资源键在加载时验证，原生资源仍由Unity保留。示例cube Cue是明确表现配置，不能替代缺失的prefab。

前端工程操作检查使用现有 TypeScript 和 Node 内置测试，无新增测试框架依赖：

```powershell
cd Tools/SkillLab/Web
npm run test:authoring
```

预置工程为 `Content/SkillLab/project.json`，现有 42 个模板，涵盖射击、区域、近战/位移、射线、召唤、Buff、投射物行为、结算事件、弹药换弹、传送弹、木桶连锁和范围引爆。“新建”可从模板复制并分配新技能/定义身份；补入缺失的技能/Buff/蓝图依赖，同身份资源复用工程现有版本，保留本地编辑。第一次启动会复制工程到 `Tools/SkillLab/.local/project.json`，后续保存只改这份工作文件；升级示例不会覆盖已保存工程。预览改变参数或切换技能后重新校验、创建独立世界；校验/重建期间禁用施放和播放，成功后显示“当前配置已应用”，错误时显示字段路径。拖动技能或 Buff 图节点只改布局，不重建战斗。暂停、单步、倍速和重置不调用 Unity。

引导模式按住“施放”按钮或空格/Enter 开始，松开停止；需要先播放，或暂停后逐帧。持续引导一直到松开/耗尽/中断；关闭持续开关则按引导时长结束。场景获得焦点后 WASD/方向键移动；按住施放按钮时也可用 WASD。连续施放可自动保持引导；失焦会释放输入。“打断”经过核心状态机。逐段耗能对有限连发生效，首段预付，后续段在触发时扣费。

蓄力模式按下时扣启动能量并开始冷却。早于最小时长松开则取消且不退款；达到最小时长后松开释放，倍率在最小/最大时长之间线性增长。开启“满蓄自动释放”会到最大时长自动发射，关闭时满蓄等待松开。持续耗能只在保持蓄力期间扣除；释放后延迟/动作不再持续扣能。失焦和指针取消直接取消，不当作有效释放。倍率随每个弹体保存，在 `Atk * Coeff + Flat` 乘倍率后再减防御。规则见 ADR-0005；不声明为原视频未公开字段的原实现。

“试验资源”可分别配置能量上限、初始能量、每秒恢复。初值为空/null 表示满能量，显式值超出上限拒绝生效。配置视图的“应用”先经过宿主完整校验，坏文本保留以便修复，不覆盖当前有效工程。

事件行提供作者节点、来源、目标和实体定位，伤害明细区分普通伤害与暴击，“伤害”筛选包含两者。“节点执行”表示实际效果入口执行，不能等同成功伤害。点击节点切到对应技能/Buff/共享Timeline/Projectile/Area图并选中节点；查看其他图会保留当前预览根与世界，直接从技能库切换则正常重建。完整实体身份包含世代，已回收会明确提示，重置会清空实体选择。运行实例也可定位定义；无法确定的来源保留空值，见ADR-0031。

运行固定步先积分所有角色的自主/技能位移，再做弹体、近战、冲刺和Hitbox查询；受击位移与重力在结算后积分。Timeline最后一个有效区间保留判定与控制租约，命中结算后才自然结束，下一步恢复自主走动。刚到Clip起点而没有有效时间交集时不提前打开判定或无敌。冲刺范围来自实际走过的碰撞路径，离散传送不算沿途攻击；网页和Unity共用该顺序，见ADR-0030。

伤害节点可选择当前目标或范围结算；命中点爆炸选“范围结算 / 事件指定点”，调半径与目标上限（0=全部）。next 连线在本次范围结算之后执行一次，不对每个命中目标重复执行。

“目标 / 区域 / 动作”可向当前目标/自身投递 apply，或在明确的事件点、目标位置、来源位置做圆查询。开启“持续区域”创建独立运行实例，编辑寿命、脉冲间隔和生成时脉冲；apply/enter/exit/stay/expire 端口连接效果。脉冲小于逻辑步长时补齐所有合法触发点，到期时点本身不脉冲。自然到期按 Exit→Expire→回收处理，Owner 死亡只清理 Exit 和实例。来源归属与空上下文规则见 ADR-0006。

传递方式选择“近战判定”后可编辑刺击/扇形/360°，分别控制距离、宽度/角度、前摇、有效时长和总目标上限，每次动作对同一完整实体最多命中一次。选择“位移攻击”可配置冲刺/闪现：冲刺按距离和速度推进、沿途扫掠；闪现只在延迟后的精确落点结算，超射程点在扣费前拒绝。有效形状由核心事件绘制，打断关闭。

动作必须从施放输出或其顺序链调度，不能从投射物/AoE 的事件里隐式启动角色动作；普通命中效果依然可组合。连发/引导的重叠冲刺会在校验时拒绝。时序与动作规则见 ADR-0007；障碍规则见 ADR-0008。

“试验障碍”可添加轴对齐矩形，编辑 X/Z、宽/深或移除；均作为工程 JSON 保存，改动校验成功后重建预览，撤销可恢复。角色以 `collisionRadius`（默认 0.4m）做移动净空检测，非法尺寸/重复 ID/出生重叠会拒绝。普通移动、冲刺与弹体在薄墙前停止，近战不能穿墙。闪现允许跨越沿途墙，但落点必须留出角色净空，射程或落点不合法时施放守卫不扣费。

射线使用“射线判定”，编辑攻击距离和全宽，开启“射线穿透”后可配置目标上限，0 为全部。按实际接触距离命中；不穿透时最近目标截断，穿透时继续到目标预算、墙或射线末端。apply 每命中目标执行，wall 仅到墙时执行，complete 始终在结束时执行一次。射线显示实际终点，不把射线画过阻挡物。

投射物的飞行距离是累计路径长，最大寿命是独立秒数；枪口前移不计飞行距离，但也会检查墙。端口 hit/wall/range/lifetime/expire 分别为命中/撞墙/射程耗尽/寿命结束/通用结束。原因效果执行一次，再执行通用结束；命中伤害先于对应结束效果，Owner 清理仍属于回收。连续扫掠避免高速越过薄墙/目标。具体契约见 ADR-0008。

“多重发射”同时生成所选数量的独立弹体，按散射角均匀分布；数量1朝瞄准正前方，360°等分一圈、不重复首尾方向。它不增加施放次数或重复扣费。可与引导组合成扇形弹幕，松开/耗尽停止新发射，已存在弹体继续运动。

“无限穿透”将每段命中上限设为0；关闭恢复1，可直接编辑有限预算。每个完整实体在同一分支只命中一次。“命中后连锁”在达到有限段预算后，从上次命中点按搜索距离选择未命中过的存活敌方；最近/随机选择复用世界随机源，墙后目标排除。额外连锁次数不含第一段，每段预算重置，但飞行距离/寿命累计；没有下一目标正常结束。无限穿透没有段终点，不能与连锁同时启用，界面会显示字段校验错误。

“命中分裂”是效果节点，接在投射物命中分支，可用继续端口放在伤害之前或之后；其他没有投射物命中上下文的端口会被拒绝。子弹从碰撞点沿入射方向散开，使用同一弹体定义，下一逻辑步生成；子弹Power乘倍率、代数加1、寿命重新从0开始，继承祖先完整命中集合，兄弟分支独立。射程可继承父弹命中点剩余路径长，或使用固定子弹距离。最大代数0关闭分裂，最多8代；同一次发射及后代最多256枚，全世界最多512枚存活，超限记录实际拒绝事件。规则见ADR-0011。

投射物运行实例显示原技能、CastId、代数、累计路径/射程与剩余连锁；再次施法不改变旧弹体身份。底部投射物为累计实际生成，连锁/分裂为实际触发次数；分裂记录的数量表示成功排入生成队列，Owner死亡或世界上限仍可能在下一步拒绝生成。

“飞行轨迹”选择方向飞行、加减速、回旋返回或地面弹跳。追踪转速/搜索/丢失重选可与直线、加速和弹跳组合；回旋出程可以追踪，返程以当前Owner方向为准。加速度可为负，速度限制在0与上限之间，减速到0后年龄继续推进、按寿命结束；最大速度不得低于初始速度。距离是Core精确积分后的平面路径，射程不会被速度变化或反射重置。

回旋在“开始返回时间”切换，按返回速度持续追逐原完整Owner身份，连续进入收取半径时执行returned/通用结束；射程/寿命/墙/有限命中预算仍可先终结。返程不再连锁去找其他目标，也不清除已命中集合。示例采用无限穿透，保证弹体能完成往返。

地面弹跳编辑发射高度、初始竖直速度、重力、恢复系数和额外反弹次数。真实落地后按恢复系数反向竖直速度，耗尽次数或无有效反弹速度时ground结束。网页显示影子、逻辑高度标记，Unity物体读取同一个Y；目标和墙碰撞仍使用现有X/Z平面规则，竖直高度不额外增加飞行距离。分裂在命中高度生成并继承父弹瞬时竖直速度，不重复加发射高度。

效果节点的“结算类型”可切换伤害、受击与状态、治疗、Buff、驱散、Cue、分裂或扣血后条件。切换保留节点身份和适用端口，用新类型默认值替换字段；撤销恢复原类型及其参数。“受击与状态”复用真实组件，包含硬直、击退、击倒、无敌、击飞、向点拉动和增加护盾；外部位移仍经过统一Motor/Collision，不隐式增加硬直。

伤害选择物理或通用元素。物理减Def，通用元素不减物理Def；“计入加成”开启时使用Atk×Coeff+Flat并应用来源伤害倍率，关闭只用Flat且不应用来源倍率。Power、暴击、目标倍率仍生效。完整顺序与Buff叠层位置见ADR-0013。“伤害明细”列出基础、倍率后、减防后、暴击后、最终计算、护盾吸收、实际扣血和过量，并显示原技能、CastId与HitIndex。总伤害为实际护盾吸收+HP损失，过量单独显示。治疗报告实际恢复值，死亡目标不会被普通治疗复活。

“试验角色属性”选择施法者或目标，编辑初始生命、攻击、物理防御、护盾和双方伤害倍率；校验成功后重建预览并随工程保存。运行实例显示实际护盾、高度和属性。

每个技能可添加一个“技能事件”根，连接实际扣血命中、暴击扣血、击杀、自然完成、撞墙终结、射程耗尽、通用投射物结束。纯护盾/无敌/0扣血不触发扣血事件，击杀只认首次HP归零；完成只认自然Finished，取消/打断/松开不算自然完成。事件按捕获的原技能/CastId执行，旧弹体不会触发新技能的事件；事件产生的追加伤害、Buff周期和AoE不重复触发技能事件总线，普通伤害仍实际生效。

“扣血后条件”只在当前调用上一个伤害结果实际扣血且Source/Target完整身份相符时执行apply，勾选“仅来源最近施法”还检查原CastId。next始终顺序继续。范围结算的next在整个范围后执行一次，不合并各目标的伤害资格；需要逐目标结果时使用技能命中事件或目标投递中的效果链。事件/条件的Source、Point及递归规则见ADR-0013。

“额外撞墙反射次数”独立于轨迹类型，0表示撞墙直接结束；大于0时按连续扫掠法线反射，消耗实际接触耗时、继续推进本步余量。成功反弹投递bounce端口并记录ground-bounce或wall-bounce，最后落地/撞墙才投递ground/wall及通用结束。初始重叠没有有效法线时直接终结，避免无限反射。运动协议见ADR-0012。

“召唤分身”选择蓝图、作用中心、数量、布置半径、寿命及同来源存活上限。数量为 1 时落在中心，多体围绕中心等角度排列；位置被障碍占用时跳过该位置，不自动换点、不退施放费用。每 Owner/定义最多 64 个，每 World 最多 128 个召唤体。右侧“召唤蓝图”编辑攻击技能引用、生命/攻防/移速、能量和 AI 距离/保持时间；已被引用的蓝图不能直接移除。

分身使用实际 Actor/组件和独立克隆 BT，通过与玩家相同的 SkillCastComp 扣能、开冷却和保持/释放引导/蓄力。伤害来源是分身本身，Owner 为归属。生成 apply、自然到期 expire 和通用 removed 端口分别执行；自然到期先 expire 后 removed，Owner 死亡/失效或手动移除只执行 removed，并清理全部后代。“运行实例”显示归属、技能、剩余时间、能量并允许移除。统计中的施放次数包括玩家与分身成功施放总数，生成数量为累计值。规则见 ADR-0009。

“Buff定义”打开共享定义及其独立生命周期图，“返回技能”回到原技能图；左侧始终预览当前技能。可新建 Buff、编辑名称、永久/持续时间、周期、最大层数、互斥组、Tag 与属性修正。策略有刷新时长、增加层数并刷新、独立实例、已有则拒绝。属性修正每实例挂载一次，叠层伤害通过伤害节点的“按Buff层数缩放”实现；多个独立实例各自生效。周期必须大于0才能连接周期效果。

唯一生命周期根提供首次施加、实际增层、周期、自然到期、持有者受击、持有者施法、移除清理端口，复用普通效果节点；根不能删除/禁用。自然到期先到期再移除，驱散/互斥/死亡仅移除；释放属性与 Tag 后执行移除效果。卸载静默清理。Buff 使用逻辑时间，出生帧不推进、Hitstop 冻结；周期在 interval 整数时点触发，等于到期终点不触发，刷新保留周期相位。详见 ADR-0010。

技能“施加 Buff”节点引用共享定义，可作用当前目标或效果来源自身；驱散按 Buff、互斥组、Tag、当前来源筛选。“来源独立的减速光环”用区域 enter 施加独立实例、exit 按该区域来源驱散，重叠光环互不移除对方状态。治疗节点经过实际 HealEffect。运行实例显示 Buff 来源/层数/剩余时间，以及最终属性和 Tag；“驱散”移除所选实例并立即恢复状态。

运行实例显示区域半径与剩余时间，网页/Unity 读取同一实际圆查询或区域快照；范围不是预录动画。模式切换删除失效生命周期连线，可撤销恢复；保留下来的断开节点需要重新连接或删除，校验不会静默执行它们。

## Unity 发布与运行

如果发布后SkillLab保留旧技能，先看HUD的F6/F7技能ID和修订。磁盘有更新会显示待载入提示，按F5或点击“Reload published F6 / F7”应用。两个技能共用普通射击、Buff或其他定义时，单槽修改可能与另一槽旧快照冲突；网页会显示原因。点击“同步两槽”可按当前工程重建两槽各自的技能闭包，再到Unity重载。同步不会把两个槽改成同一个技能。

发布修订校验直接检查文件内的JSON载荷，避免.NET/Mono浮点序列化精度不同引起误判；修改或损坏文件仍拒绝加载，保留已有会话。

正式资源目录区分actor和body：角色使用Animator状态，弹体/区域/木桶使用只读Prefab、旋转速度和逻辑时钟采样。实体节点选择外观资源，目录面板编辑资源键、缩放和旋转；SkillLab与Arena都读取实际body Prefab。角色Body/Head/Muzzle锚点在JSON定义，Cue可附着锚点。已恢复原弹体/区域/木桶/12种Cue与贴图材质，旧材质转换为URP；源提交没有音频文件，当前未伪造原音效。

“角色生成与 AI”面板编辑正式角色的生成采样、每次生成生命/攻击增长、整数随机范围和速度饱和曲线；敌人成长按累计生成序号计算，死亡补怪不会降低序号，重开归零。生成时先写入属性，再向表现发布角色。SkillLab仍使用明确的试验角色初值，正式Arena才在出生时应用采样。

玩家角色还可设置“输入缓冲时间（秒）”。Arena按原配置为0.8秒，队列最多3次按下，按各自接收时的角色时间过期；新输入超限移出最旧项。角色顿帧冻结输入年龄，暂停/失焦清空；按住普攻不占输入队列。正式Combo预览采用同一Arena玩家窗口。

循环表现节点可选“按Buff层数分级”，配合“表现层数上限”分别创建`实例键_层数`；停止时清理所有层。回旋灼烧与地面燃烧为独立定义，前者3秒/0.5秒/3层，后者2秒/0.4秒/1层，均按当前来源攻击结算。Buff循环可跨施法继续，动作循环仍按施法身份独立清理。

AI可选择“游走与定时射击”，独立配置首次换向、随机角度/间隔、首次射击和后续间隔。两个行为按角色独立计时，受击/倒地/角色顿帧会冻结；定时射击走普通施放守卫。正式原敌人首2秒换向、首3秒射击、随后2–5秒一发；玩家种子1的初始攻击为54，前两名敌人生命50/52，后续持续递增。修改后“发布正式内容”，Arena按F5重载，当前执行中的角色不会被原地改写。

“共享区域”管理独立的范围、运动和生命周期效果图，可从持续区域节点提取。生成中心和前方偏移保留在引用节点，原炸弹的命中/撞墙/寿命结束与延迟炸弹共用一份爆炸区。定义支持根保护、引用检查、复制/改名/替代删除/合并和撤销；两槽共享区域版本冲突时保留有效会话。

表现节点可选择单次、开启循环或停止循环。循环实例键只在同一完整实体内生效；“施法结束自动停止”用于动作效果，Buff表现可关闭它并在移除端口停止。Unity在打断、死亡、失效来源和重开时清理相应表现。当前原翻滚仍使用占位Cue，原粒子、骨骼锚点和音频继续迁移。

正式Arena的Roll接原2002：.9秒动作、.1–.8无敌、.2–.8移动2米、.1秒施加.7秒减伤。Fire3接原2007弹跳炸弹：命中/撞墙爆炸，寿命结束留下三秒延迟炸弹，继而再次爆炸并生成三秒燃烧区。原2012确认后可接Fire3；普攻首段不能跳过二段进入该分支。

“共享弹体”管理独立的飞行、接触和终结效果图。“提取为共享弹体”移动普通弹体及其效果分支，原节点变成引用；被其他节点或时间轴直接使用的分支会拒绝提取。共享根保留运行身份，不能删除或禁用；发射数量和散射角配置在使用者的引用节点。定义支持复制、改名、替代删除、合并与撤销；发布包包含实际弹体/Buff/时间轴依赖，两槽公共定义版本冲突时保留当前有效会话。

回旋可选原正弦采样曲线，出程和返程按每个弹体自己的逻辑年龄采样。“按时间表弹跳”编辑首跳高度和严格递增的落地点秒数数组，后续高度按分段时长平方缩放；每次落地发反弹事件，最终寿命独立结束。关闭“撞墙终结”后停在碰撞点，逻辑年龄、落地事件与寿命继续推进。伤害反馈可沿用技能或显式关闭，“按反馈推导最低顿帧”与显式帧数取较大值。

选择当前技能，点击“发布到 F6 / F7”，原子写入 `Assets/StreamingAssets/Combat/f6.json` 或 `f7.json`。发布包包含选中技能、引用的 Buff、蓝图与攻击技能完整闭包及校验修订号，仍由同一工程语义派生。技能/Buff 跨类型递归或超过 8 层的依赖拒绝。发布成功表示文件已经落盘，界面会提示游戏的加载操作。

在 Unity 打开 `Assets/Scenes/HaloCombat/SkillLab.unity` 并运行；场景也可从 `Combat/Create JSON Skill Lab Scene` 重建。按 F5 重读已发布文件并重建试验世界，F6/F7 施放对应槽，鼠标施放上次选择槽；引导时按住、松开对应键。WASD 移动，Space 暂停。首次尚未载入时按槽键会载入一次。两槽共用角色和能量/冷却，普通施放不重置会话。

两槽需要来自同一工程；技能、Buff 和蓝图的同身份不同版本均拒绝混用。试验场布置以 F6 为准，只有 F7 时采用 F7。想更新场景、共享 Buff 或公共攻击技能时同步发布两槽。读取损坏文件会保留原有效世界及待执行周期，并在 HUD 显示错误；成功重载才清理旧输入/弹体/事件。该试验场只读取 JSON，不使用 SO/代码内容回退。

网页宿主与 Unity SkillLab 使用同一 `SkillSimulation`、工厂和只读快照。正式V1–V4、训练场和Arena已接入JSON；弹药/缺弹换弹、追踪弹/Fire4、木桶链爆/Fire5及角色独立顿帧/受伤反馈已完成；其余历史产品能力和最终视觉对照仍未完成。

“可破坏物”节点保存生命、组/阵营、受伤上限、自伤周期、数量/净空、外观与归属清理；生成/死亡/移除端口复用普通效果链。死亡接“区域作用”可限制目标阵营，接“范围引爆物体”可引爆同组邻居。运行实例显示真实生命、拥有者、组和下次自伤，并可手动移除。手动移除/重开不当作死亡爆炸，正式木桶0.1秒在玩家前方.55米生成，HP5、5秒自伤1、普通受伤最多1；爆炸目标独立停3帧并发Heavy受伤反馈，原资源仍按N08迁移。

伤害节点可分别配置“世界顿帧”“攻击者顿帧”“目标顿帧”和命中反馈等级；角色请求在下一固定步统一生效，同角色取较大值，已有弹体不随Owner冻结。运行实例显示每Actor停止/剩余帧和角色逻辑时间。伤害后连接“受伤反馈”节点，默认仅本次实际扣血且目标仍存活时生效；它只发视觉反馈，不把目标切到硬直状态。实际硬直使用原“受击与状态”节点。协议及边界见ADR-0019与独立顿帧验收记录。

完整正式工程可展开“连招输入与接续”编辑多个前驱、令牌、Tag/命中确认、优先级与目标；空前驱是起手，播放中自动要求取消窗。应用时完整校验，失败保留草稿，成功可撤销；增删/改名仍同步类型化技能引用。预览“发送输入”经过实际InputBuffer/Combo，不重建会话；直接施放按钮依然只是选中技能。命中敌方无敌/护盾/0伤害也可取得1017资格，资格只属于当前有效Skill/CastId；完整查表后资格消费，输入只在成功施放后消费。事件与实例显示真实资格、匹配边和缓冲状态。
